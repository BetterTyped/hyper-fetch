# Interface tour

HyperFlow has two levels. The **home screen** lists every app that connected. Each **app** has its own pages for its
requests, cache, queues, sockets and dbs. This page shows where everything is.

---

## The home screen

HyperFlow opens on **Applications**. Each card is one app, named by the `appName` you passed to the plugin.

An app that disconnects stays on the list with the data HyperFlow collected, and picks up where it left off when it
reconnects under the same name. To remove an app, open the **⋮** menu that appears when you hover its card.

**Support** and **Feedback** at the bottom of the sidebar open GitHub issues and discussions.

| Page                                                    | Use it to                                                         |
| ------------------------------------------------------- | ----------------------------------------------------------------- |
| [App](/docs/hyper-flow/features/dashboard.mdx)          | See request totals, success rate, slow endpoints and cache usage  |
| [Network](/docs/hyper-flow/features/network.mdx)        | Find a request and inspect its payload, response and timing       |
| [Cache](/docs/hyper-flow/features/cache.mdx)            | Check what is cached and edit, invalidate or remove entries       |
| [Queues](/docs/hyper-flow/features/queues.mdx)          | Watch queued requests, and stop, start or clear a queue           |
| [Sockets](/docs/hyper-flow/features/sockets.mdx)        | Read realtime messages and the connection state                   |
| [DB](/docs/hyper-flow/features/db.mdx)                  | Look at collections, live queries and the outbox                  |
| [Settings](/docs/hyper-flow/features/settings.mdx)      | Set the history limit and the errors you simulate                 |

When an app is disconnected, its pages show an **Offline** badge at the top. You can still read everything HyperFlow
collected, but cache edits and queue controls need the app to be connected.

---

## Lists and details

The Network, Cache and Queues pages work the same way. A list fills the page, with a search field and filters above it.
Select a row to open its details in a panel next to the list. Drag the panel's edge to resize it, close it with the
**X** in its toolbar, and find actions such as **Remove** or **Stop** under **Actions** in the same toolbar.

Every value in the details is shown as a tree. Expand objects and arrays with the arrows, and copy any value with the
button next to it.

## Keyboard shortcuts

| Shortcut                             | Action                                         |
| ------------------------------------ | ---------------------------------------------- |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>I</kbd> | Copy a screenshot of the window to the clipboard on macOS |
| <kbd>⌘</kbd> <kbd>R</kbd>            | Reload the window (<kbd>Ctrl</kbd> <kbd>R</kbd>) |
| <kbd>⌘</kbd> <kbd>M</kbd>            | Minimize the window on macOS                   |
| <kbd>⌘</kbd> <kbd>W</kbd>            | Close the window. On macOS, HyperFlow keeps running in the background |

Reloading the window keeps every app and its settings but empties the collected requests, cache and messages.

:::secondary Summary

The home screen lists your apps, each app has seven pages in its sidebar, and every list opens its details in a side
panel. The [feature pages](/docs/hyper-flow/features/dashboard.mdx) explain each page in depth.

:::
