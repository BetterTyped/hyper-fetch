# HyperFlow

HyperFlow is a desktop app for macOS, Windows and Linux that shows what the data layer of your HyperFetch app is doing,
while it runs. Add the [devtools plugin](/docs/integrations/plugin-devtools) to your client, and HyperFlow
lists every request with its payload, response and timing, the cache with its fresh and stale entries, the queues,
socket traffic and `@hyper-fetch/db` collections.

## Get started in three steps

1. **[Download HyperFlow](/docs/hyper-flow/download)** for your system and open it.
2. **Add the plugin** to your client:

   ```ts title="api/client.ts"
   import { createClient } from "@hyper-fetch/core";
   import { DevtoolsPlugin } from "@hyper-fetch/plugin-devtools";

   export const client = createClient({ url: "https://api.example.com" }).addPlugin(
     // highlight-next-line
     DevtoolsPlugin({ appName: "My App" }),
   );
   ```

3. **Run your app.** It shows up on the HyperFlow home screen as soon as the plugin connects.

[Connect your app](/docs/hyper-flow/connecting) covers installation, development-only setup, Node.js backends,
sockets and dbs.

## How it works

```mermaid
flowchart LR
  subgraph app [Your app]
    C["HyperFetch client"] --> P["DevtoolsPlugin"]
    S["Sockets and dbs"] --> P
  end
  P -- "events over WebSocket<br/>ws://localhost:2137" --> H["HyperFlow<br/>local server"]
  H --> UI["HyperFlow window"]
  UI -- "cache edits, queue controls" --> H
  H --> P
```

The plugin listens to the client's events and sends them to a small server that HyperFlow runs on your machine, on port
`2137` by default. HyperFlow keeps what it receives in memory and shows it live. The connection also works the other
way: when you edit a cache entry or stop a queue in HyperFlow, the plugin applies the change in your app.

Your requests and responses travel only between your app and HyperFlow on your machine.

---

## Why a desktop app

Browser devtools only see what runs in their tab. The Network tab shows HTTP traffic, but not which requests were
answered from cache, joined an identical request or waited in a queue, and React DevTools shows components, not data.

HyperFlow gets this from the client itself, so it works wherever the client runs. A browser tab, a Next.js server, a
Node.js worker and a React Native app all connect the same way, and each appears as its own application in one window.
The trade-off is one more app to start while you develop.
