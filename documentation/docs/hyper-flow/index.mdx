# HyperFlow, a devtools app for requests, cache and queues

HyperFlow is a desktop app for macOS, Windows and Linux that shows what the data layer of a HyperFetch app is doing. Your
client connects to it through the [devtools plugin](../integrations/plugin-devtools/index.mdx), and HyperFlow lists every
request with its payload, response, headers, status and timing, the cache with fresh and stale entries, the queues, and
socket traffic. If you know react query devtools, it covers the same ground for HyperFetch, from a separate window
instead of a panel inside the page.

HyperFlow is in alpha.

- **Inspect** every request and filter by endpoint, method, key, success, failure, paused or canceled.
- **Browse and edit the cache**, and watch hooks pick up the change.
- **Control queues**: stop, start and clear them to test slow and offline paths.
- **Read sockets**: connection state, messages in and out, and errors for WebSocket and SSE.

---

## Why a desktop app and not a browser extension

Browser devtools, including the Chrome React DevTools extension, only see what runs in that tab. React DevTools shows
the component tree and the profiler. The Network tab shows HTTP traffic, but not which requests were served from
cache, deduplicated or waiting in a queue.

HyperFlow gets that from the client itself. The plugin sends events over a local WebSocket, so the app does not have to
run in Chrome at all: a Node.js backend, a script or a browser tab all connect the same way, and each shows up as its
own connection under its `appName`. The trade-off is one more app to start while you develop, and no inline panel in
the page.
