# Download

HyperFlow runs on macOS, Windows and Linux. The button below picks the build for your system, and every other build of
the newest version is listed under it.

<HyperFlowDownloads />

---

## Installing

1. **macOS**: open the `.dmg` and drag HyperFlow to Applications. The `.zip` holds the same app without an installer.
2. **Windows**: run the `.exe` installer. The `.zip` is a portable build that runs without installing.
3. **Linux**: install the `.deb` on Debian or Ubuntu (`sudo apt install ./hyperflow_*.deb`) or the `.rpm` on Fedora
   or RHEL (`sudo dnf install ./HyperFlow-*.rpm`). The `.zip` holds the app for other distributions.

Once it runs, [connect your application](/docs/hyper-flow/connecting) with the devtools plugin.
