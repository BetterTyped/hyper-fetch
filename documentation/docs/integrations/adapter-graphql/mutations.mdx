Mutations are used to modify data on your GraphQL server. This guide will show you how to create and execute mutations
using Hyper Fetch.

:::tip What you'll learn

- How to create a GraphQL mutation.
- How to pass variables to a mutation.
- How to handle mutation responses.
- How to refetch the queries a mutation changed.

:::

---

## Basic Mutation

Here is a basic example of how to create a mutation to log in a user.

```tsx
import { Client } from "@hyper-fetch/core";
import { GraphqlAdapter } from "@hyper-fetch/graphql";
import gql from "graphql-tag";

// 1. Initialize the client
const client = new Client({ url: "http://localhost:3000/graphql" }).setAdapter(GraphqlAdapter());

// 2. Define types for the variables
type Variables = {
  username: string;
  password: string;
};

// 3. Create the mutation request
const login = client.createRequest<{ response: boolean; payload: Variables }>()({
  endpoint: gql`
    mutation Login($username: String!, $password: String!) {
      login(username: $username, password: $password)
    }
  `,
});

// 4. Send the mutation with variables
const { data, error } = await login.send({
  payload: {
    username: "Some username",
    password: "Some password",
  },
});
```

Similar to queries, you can also use the `.setPayload()` method to provide variables for your mutation.

```ts
const { data, error } = await login
  .setPayload({
    username: "Some username",
    password: "Some password",
  })
  .send();
```

## Refetching queries after a mutation

A mutation often changes data that queries already hold in the cache. `matchGqlOperation` matches the cache keys of
every request of a query document - with any variables, params, query params and method. Pass it to
`client.cache.invalidate()`, and the active queries of the operation refetch, like `refetchQueries` in Apollo.

```ts
import { matchGqlOperation } from "@hyper-fetch/graphql";

const updateUser = client.createRequest()({ endpoint: UpdateUserDocument });

const { success } = await updateUser.send({ payload: { id: "1", name: "Ann" } });

if (success) {
  // GetUser(id: 1), GetUser(id: 2)... are all marked stale and refetched where they are used
  client.cache.invalidate(matchGqlOperation(GetUserDocument));
}
```

- Pass a document to match its requests on every url path of the `document` option, or a request to match only its
  own path.
- Documents with the same operation name but other fields are other operations, so they are not matched.
- `invalidate` takes a list, so one mutation can refetch many operations:
  `client.cache.invalidate([matchGqlOperation(GetUserDocument), matchGqlOperation(GetUsersDocument)])`.
