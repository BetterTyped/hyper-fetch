# Community integrations

Adapters, plugins and other packages for HyperFetch built by the community. No packages have been added yet.

---

## Add your package

Built an adapter, a plugin or a framework integration for HyperFetch? Edit this page on GitHub and open a pull request
with the package name, a link to npm or the repository, and one sentence on what it connects. To build one, start from
the [custom adapter guide](/docs/guides/core/advanced/custom-adapter) or the [Plugin](/docs/core/plugin) page.

Missing an integration you need? [Open an issue](https://github.com/BetterTyped/hyper-fetch/issues) and describe what
you want to connect.
