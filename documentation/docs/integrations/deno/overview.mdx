# Deno

HyperFetch runs on Deno through its npm support and Deno's native `fetch`, so `createClient`, `createRequest` and
`send()` work as they do in Node.js and the browser. Use it in Deno scripts, servers and edge functions on Deno Deploy.

:::tip Purpose

1. **No build step**: import `@hyper-fetch/core` with an `npm:` specifier and run the file.
2. **Native fetch**: no polyfill and no Deno-specific adapter.
3. **Safe on shared servers**: outside the browser the client caches nothing unless a request has a scope.

:::

---

## Install

Add the package to `deno.json`, or skip this step and import it with an `npm:` specifier:

```bash
deno add npm:@hyper-fetch/core
```

---

## Send a request

```ts title="main.ts"
import { createClient } from "npm:@hyper-fetch/core";

const client = createClient({ url: "https://api.example.com" });

const getUsers = client.createRequest<{ response: { id: number; name: string }[] }>()({
  endpoint: "/users",
});

const { data, error } = await getUsers.send();
console.log(error ?? data);
```

```bash
deno run --allow-net=api.example.com main.ts
```

---

## Use it in a server

`Deno.serve` handles requests from many users with one client. Outside the browser the [client](/docs/core/client)
caches nothing unless the request has a scope, so set one to cache per user:

```ts title="server.ts"
import { createClient } from "npm:@hyper-fetch/core";

const client = createClient({ url: "https://api.example.com" });
const getProfile = client.createRequest<{ response: { name: string } }>()({ endpoint: "/me" });

Deno.serve(async (req) => {
  const token = req.headers.get("Authorization") ?? "";
  // highlight-next-line
  const { data, error } = await getProfile.setHeaders({ Authorization: token }).setScope(token).send();

  return Response.json(error ?? data, { status: error ? 502 : 200 });
});
```

---

## Runtime quirks

- **Permissions**: Deno asks for network access. Pass `--allow-net`, or `--allow-net=api.example.com` to allow only your
  API.
- **Deno Deploy and Supabase Edge Functions** run Deno, so the same code runs there.
