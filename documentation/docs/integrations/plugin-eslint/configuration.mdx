# Configure eslint-plugin-hyper-fetch in flat config

Set up the HyperFetch ESLint plugin in flat config (`eslint.config.*`, the only format of ESLint 10) or in a legacy
`.eslintrc` file, and choose the severity of each rule.

:::tip Purpose

1. **Flat config first**: `configs.recommended` is a flat config object.
2. **Legacy support**: `configs["recommended-legacy"]` keeps `.eslintrc` setups on ESLint 8 working.
3. **Fine-grained control**: set each rule's severity yourself when the preset does not fit.

:::

---

## Recommended config

The default export is the plugin. Its `configs.recommended` preset registers the plugin under `hyper-fetch` and sets
both rules to `"error"`. Pair it with a block that parses TypeScript files with typescript-eslint:

```js title="eslint.config.mjs"
import hyperFetch from "eslint-plugin-hyper-fetch";
import tseslint from "typescript-eslint";

export default [
  {
    files: ["**/*.{ts,tsx,mts,cts}"],
    languageOptions: { parser: tseslint.parser },
  },
  hyperFetch.configs.recommended,
];
```

The preset has no `files` key, so it applies to every file your config lints. Spread it to scope it:

```js title="eslint.config.mjs"
{ ...hyperFetch.configs.recommended, files: ["src/**/*.ts"] },
```

## Custom config

Register the plugin and list the rules yourself to pick their severity:

```js title="eslint.config.mjs"
import hyperFetch from "eslint-plugin-hyper-fetch";
import tseslint from "typescript-eslint";

export default [
  {
    files: ["**/*.{ts,tsx,mts,cts}"],
    languageOptions: { parser: tseslint.parser },
    plugins: { "hyper-fetch": hyperFetch },
    rules: {
      "hyper-fetch/client-generic-types": "error",
      "hyper-fetch/request-generic-types": "warn",
    },
  },
];
```

Each rule takes `"off"`, `"warn"` (reported, exit code stays 0) or `"error"` (exit code 1). Registering the plugin next
to `hyperFetch.configs.recommended` is fine: both hold the same plugin object, so ESLint does not report
`Cannot redefine plugin "hyper-fetch"`.

## Legacy config (`.eslintrc`)

ESLint 8 still reads `.eslintrc.*` files. Extend the legacy preset there, or register the plugin by name and list the
rules:

```json title=".eslintrc.json"
{
  "parser": "@typescript-eslint/parser",
  "extends": ["plugin:hyper-fetch/recommended-legacy"]
}
```

```json title=".eslintrc.json"
{
  "parser": "@typescript-eslint/parser",
  "plugins": ["hyper-fetch"],
  "rules": {
    "hyper-fetch/client-generic-types": "error",
    "hyper-fetch/request-generic-types": "error"
  }
}
```

:::caution Use the legacy preset in `.eslintrc`

`plugin:hyper-fetch/recommended` points to the flat preset, which `.eslintrc` cannot load. Use
`plugin:hyper-fetch/recommended-legacy` instead.

:::
