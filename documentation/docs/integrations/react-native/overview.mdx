# React Native

HyperFetch runs in React Native and Expo with React Native's `fetch` and no native module, and the hooks from
`@hyper-fetch/react` work as they do on the web. A phone has no browser window, so you tell the client where focus and
network status come from.

:::tip Purpose

1. **Same API as the web**: `createRequest`, `send()`, `useFetch` and `useSubmit` need no changes.
2. **Refetch on resume**: `AppState` tells HyperFetch when the app comes back to the foreground.
3. **Offline aware**: `NetInfo` holds requests while the device is offline and resumes them when it reconnects.

:::

## Send a request

Give the client an [`AppManager`](/docs/core/managers) that reads focus from `AppState` and the connection from
`NetInfo`:

```ts title="client.ts"
import { AppState } from "react-native";
import NetInfo from "@react-native-community/netinfo";
import { AppManager, createClient } from "@hyper-fetch/core";

export const client = createClient({
  url: "https://api.example.com",
  // React Native has no document, so the cache would be off in the default "server" mode
  mode: "client",
  // highlight-start
  appManager: () =>
    new AppManager({
      initiallyOnline: () => NetInfo.fetch().then((state) => !!state.isConnected),
      onlineEvent: (setOnline) => NetInfo.addEventListener((state) => setOnline(!!state.isConnected)),
      focusEvent: (setFocused) => {
        const subscription = AppState.addEventListener("change", (status) => setFocused(status === "active"));
        return () => subscription.remove();
      },
    }),
  // highlight-end
});

export const getUsers = client.createRequest<{ response: { id: number; name: string }[] }>()({
  endpoint: "/users",
});
```

Then use the hooks in your screens:

```tsx title="UsersScreen.tsx"
import { FlatList, Text } from "react-native";
import { useFetch } from "@hyper-fetch/react";

import { getUsers } from "./client";

export function UsersScreen() {
  const { data, loading, error } = useFetch(getUsers);

  if (loading) return <Text>Loading...</Text>;
  if (error) return <Text>Could not load users</Text>;

  return (
    <FlatList
      data={data}
      keyExtractor={(user) => String(user.id)}
      renderItem={({ item }) => <Text>{item.name}</Text>}
    />
  );
}
```

## Runtime quirks

- **Client mode**: the [client](/docs/core/client) picks `"client"` mode only when it finds `window` and `document`.
  React Native has no `document`, so set `mode: "client"` to keep the cache on.
- **Calling a local server**: `localhost` on a device or emulator is the device itself. The Android emulator reaches
  your computer on `10.0.2.2`, and a real device needs your computer's LAN address.
- **Persistent queues**: to keep offline requests across app restarts, see the
  [React Native environment](/docs/react/environments/react-native) page.
