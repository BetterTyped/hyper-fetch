# Bun

HyperFetch runs on Bun with its native `fetch`, so `createClient`, `createRequest` and `send()` work as they do in
Node.js and the browser. Use it in Bun scripts, servers and tests, and pair it with Elysia or Hono for a typed SDK
without codegen.

:::tip Purpose

1. **Nothing extra to install**: `bun add @hyper-fetch/core` and you are done.
2. **End-to-end types with Bun backends**: Elysia and Hono give you a typed SDK straight from your routes.
3. **Tests off the network**: `setMock()` answers requests inside `bun test`.

:::

---

## Install

```bash
bun add @hyper-fetch/core
```

---

## Send a request

```ts title="requests.ts"
import { createClient } from "@hyper-fetch/core";

const client = createClient({ url: "https://api.example.com" });

export const getUsers = client.createRequest<{ response: { id: number; name: string }[] }>()({
  endpoint: "/users",
});
```

```ts title="index.ts"
import { getUsers } from "./requests";

const { data, error } = await getUsers.send();
console.log(error ?? data);
```

```bash
bun run index.ts
```

## Runtime quirks

- **Testing with `bun test`**: mock a request with `setMock()`, so the test never reaches the network:

```ts title="users.test.ts"
import { expect, test } from "bun:test";

import { getUsers } from "./requests";

test("lists users", async () => {
  getUsers.setMock(() => ({ data: [{ id: 1, name: "Ada" }], status: 200 }));

  const { data } = await getUsers.send();
  expect(data).toEqual([{ id: 1, name: "Ada" }]);
});
```
