# Node.js

HyperFetch runs on Node.js 18 and newer with the `fetch` built into the runtime, so there is no polyfill and no
Node-specific adapter. Use it in backends, scripts and jobs that call other APIs and need typed responses and retries.

:::tip Purpose

1. **Nothing extra to install**: `@hyper-fetch/core` uses the runtime's own `fetch`.
2. **Same requests on both sides**: share request definitions between your server and your frontend.
3. **Safe on shared servers**: outside the browser the client caches nothing unless a request has a scope.

:::

## Install

```bash npm2yarn2pnpm
npm install @hyper-fetch/core
```

## Send a request

```ts title="sync-users.ts"
import { createClient } from "@hyper-fetch/core";

const client = createClient({ url: "https://api.example.com" });

const getUsers = client.createRequest<{ response: { id: number; name: string }[] }>()({
  endpoint: "/users",
});

const { data, error, status } = await getUsers.setRetry(2).send();

if (data) {
  console.log(`${data.length} users`);
} else {
  console.error(status, error);
}
```

`send()` resolves with the [response](/docs/core/request) instead of throwing, so a failed call never crashes the
process with an unhandled rejection. Requests time out after 5 seconds by default, change it with
`setOptions({ timeout: 30000 })`.

## Use it in a server

One client can serve every incoming request. Outside the browser the [client](/docs/core/client) runs in `"server"`
mode, where the cache stays off unless the request has a scope, so one user's data never reaches another. Set a scope
to cache per user:

```ts title="server.ts"
import express from "express";
import { createClient } from "@hyper-fetch/core";

const client = createClient({ url: "https://api.example.com" });
const getProfile = client.createRequest<{ response: { name: string } }>()({ endpoint: "/me" });

const app = express();

app.get("/dashboard", async (req, res) => {
  const token = req.headers.authorization ?? "";
  const { data, error } = await getProfile
    .setHeaders({ Authorization: token })
    // highlight-next-line
    .setScope(token)
    .send();

  if (error) return res.status(502).json(error);
  return res.json(data);
});
```

Data that is the same for everyone, like a public price list, can share one scope such as `setScope("public")`.

## Runtime quirks

- **Node.js 18 or newer**: older versions have no global `fetch`.
- **Typed third-party APIs**: generate an SDK from any OpenAPI document with
  `npx @hyper-fetch/cli@latest generate`, see the [OpenAPI TypeScript client](/docs/cli/openapi-typescript-client).
- **Realtime**: a `Socket` connects from Node.js too, see the
  [Node.js WebSocket client](/docs/guides/sockets/nodejs-websocket-client) guide.
