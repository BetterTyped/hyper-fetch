HyperFetch's HTTP adapter is built on the Fetch API and cancels requests with `AbortController`. These resources explain
both, which helps when you read adapter options or debug a request.

---

## [MDN Web Docs: Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API)

The reference for `fetch`, `Request`, `Response` and `Headers`, with browser support. The HTTP adapter's options, such
as `credentials` or `mode`, are `RequestInit` fields documented here.

---

## [MDN Web Docs: AbortController](https://developer.mozilla.org/en-US/docs/Web/API/AbortController)

The API HyperFetch uses to [cancel requests](/docs/guides/core/advanced/cancellation).

---

## [JavaScript.info: Fetch](https://javascript.info/fetch)

A tutorial on `fetch` with examples for JSON, form data, progress and aborting.
