# Guides overview

Guides solve one task each, such as adding authentication or keeping requests while offline, with complete code you can
copy. Use them when you know what you want to build. The [concept pages](/docs/core/overview) describe each building
block, and the [examples](/examples/getting-started/basic) are runnable apps.

:::secondary What you'll learn

1. How to **set up** a client and send typed requests.
2. How to handle **authentication, errors, retries and caching** with the core package.
3. How to fetch and submit data with **React hooks** and **sockets**.
4. How to **type** responses, payloads and errors, and how to **test** requests with mocks.

:::
