# Window and Network Events

Data on screen gets old while the user is in another tab or offline. This guide refetches it when the user comes back,
when the network returns, and pauses polling in the background, with options of
[`useFetch`](/docs/react/hooks/use-fetch).

:::secondary What you'll learn

1.  How to **refetch on window focus** with `refetchOnFocus`.
2.  How to **refetch after a reconnect** with `refetchOnReconnect`.
3.  How to **pause polling** in background tabs with `refetchBlurred`.
4.  What **`refetchOnBlur`** is for.
5.  How to set these options **for the whole app**.

:::

---

## Refetch when the user comes back

Turn on `refetchOnFocus` and `refetchOnReconnect` for data that other people change, such as an inbox or a shared
board. Both are off by default.

```tsx title="components/inbox.tsx"
import { useFetch } from "@hyper-fetch/react";
import { getMessages } from "../api/messages";

export function Inbox() {
  const { data: messages, onSuccess } = useFetch(getMessages, {
    // highlight-start
    refetchOnFocus: true,
    refetchOnReconnect: true,
    // highlight-end
  });

  onSuccess(({ response }) => console.log(`Loaded ${response.data.length} messages`));

  return (
    <ul>
      {messages?.map((message) => (
        <li key={message.id}>{message.subject}</li>
      ))}
    </ul>
  );
}
```

- Focus means the browser tab or window gains focus. In React Native it is the app returning to the foreground.
- Each event sends the request at once, even when the cached data is still fresh, and restarts the polling countdown.
- A disabled hook ignores the events.

---

## Pause polling in the background

With `refresh`, polling continues in background tabs, default `refetchBlurred: true`. Set it to `false` and the ticks
are skipped while the window is blurred. Combine it with `refetchOnFocus` so the user never sees data older than one
interval.

```tsx title="Poll only while visible"
const { data } = useFetch(getStats, {
  refresh: true,
  refreshTime: Time.SEC * 10,
  refetchBlurred: false,
  refetchOnFocus: true,
});
```

---

## Refetch when the user leaves

`refetchOnBlur` sends the request when the window loses focus. It is rarely needed: one use is loading fresh data in the
background as the user leaves, so it is already current when they come back, without a refetch on focus.

---

## Which option to use

| Situation                                             | Options                                     |
| ----------------------------------------------------- | ------------------------------------------- |
| Data that others change while the user is away        | `refetchOnFocus: true`                      |
| Mobile or unstable networks                           | `refetchOnReconnect: true`                  |
| Polling dashboards                                    | `refetchBlurred: false` + `refetchOnFocus`  |
| Data that only the current user changes               | None, invalidate after mutations instead    |

To turn an option on everywhere, set it once on the [`Provider`](/docs/react/overview#global-defaults) with
`config={{ useFetchConfig: { refetchOnFocus: true } }}`. Hook options still override it.

Focus and network state come from the client's app manager, which reads browser events. In React Native and Electron
connect it to the platform APIs first: see [React Native](/docs/react/environments/react-native) and
[Electron](/docs/react/environments/electron).

You can now keep data fresh when the user's context changes.

- You can **refetch on focus** and **after a reconnect**.
- You can **pause polling** in background tabs with `refetchBlurred: false`.
- You know when **`refetchOnBlur`** is useful.
- You can set these options **globally** on the `Provider`.
