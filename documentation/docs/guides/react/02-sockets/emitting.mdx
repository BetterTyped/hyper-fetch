# Socket Emitting

While listening for events is crucial, your application also needs to send data to the server. Hyper-fetch's
`useEmitter` hook provides a clean and efficient way to emit socket events. It gives you a dedicated `emit` function to
trigger events on demand, along with helpers to track the connection state and react to messages that could not be
sent. This hook is perfect for actions like sending messages, updating user status, or any other client-to-server communication.

:::secondary What you'll learn

1.  How to use the **`useEmitter`** hook to send data to a socket server.
2.  How to trigger an event using the returned **`emit` function**.
3.  How to react to messages that could not be sent with **`onEmitError`**.
4.  How to use helper hooks like **`onEmit`** and **`onReconnecting`** to manage the emitter's lifecycle.

:::

---

## Basic Usage

The `useEmitter` hook takes an emitter and returns an `emit` function, connection status, and several helper
hooks. You call the `emit` function whenever you want to send data to the server. A common use case is sending data from
a form.

`emit` returns `void` and has no acknowledgement callback. Messages are not queued: a message emitted while the socket
is not connected (or one whose payload cannot be encoded) is dropped and reported through `onEmitError`. Disable the
send action while `connected` is `false`, and render a [`useListener`](/docs/react/sockets/use-listener) on a reply
topic when the server needs to answer.

```tsx
function ChatInput() {
  const [message, setMessage] = React.useState("");
  const [status, setStatus] = React.useState("Waiting for message...");

  const { emit, connected, onEmit, onEmitError, onReconnecting } = useEmitter(sendMessage);

  onEmit((emitter) => {
    console.log("Event was sent!", emitter);
  });

  onEmitError(({ error }) => {
    setStatus(`Message not sent: ${error.message}`);
  });

  onReconnecting(({ attempts }) => {
    setStatus(`Attempting to reconnect... (${attempts})`);
  });

  const handleSubmit = (e) => {
    e.preventDefault();
    if (!message) return;

    // The data we send
    const payload = { message, user: "Me", timestamp: Date.now() };

    // Emit the event with payload as an options object
    // highlight-next-line
    emit({ payload });
    setMessage("");
  };

  return (
    <div className="w-full">
      <p>Connection status: {connected ? "Connected" : "Disconnected"}</p>
      <form onSubmit={handleSubmit} className="flex gap-2 mt-2">
        <input
          type="text"
          value={message}
          onChange={(e) => setMessage(e.target.value)}
          placeholder="Write a message..."
          className="p-2 border rounded-md flex-grow"
        />
        <button
          type="submit"
          disabled={!connected}
          className="bg-blue-500 text-white p-2 rounded-md disabled:bg-gray-400"
        >
          Send
        </button>
      </form>
      <p className="text-sm text-gray-600 mt-2">Status: {status}</p>
    </div>
  );
}
```

In this example, `sendMessage` is a pre-defined emitter. You can learn more about creating them in the
[sockets guide](/docs/guides/sockets/emitting). The `emit` function takes an options object with a `payload` property.
