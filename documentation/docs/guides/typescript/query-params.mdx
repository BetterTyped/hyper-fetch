# Query params type

The `queryParams` generic types the query string of a request, so filters, sorting and pagination are checked and
autocompleted. Whether the key is optional decides if callers must pass query params. For serialization and sending,
see the [query params guide](/docs/guides/core/basics/query-params).

:::secondary What you'll learn

1. How to type query params with the **`queryParams` generic**.
2. The difference between **required, optional and absent** query params.
3. What TypeScript **catches** at `send()`.
4. How to **reuse** the type with `ExtractQueryParamsType`.

:::

---

## Type the query params

```ts title="src/api/users.ts"
type UsersQuery = {
  role: "admin" | "member"; // required key
  search?: string; // optional key
  tags?: string[];
};

export const getUsers = client.createRequest<{
  response: User[];
  queryParams: UsersQuery;
}>()({ endpoint: "/users" });

await getUsers.send({ queryParams: { role: "admin", tags: ["active"] } });
```

---

## Required, optional or absent

The `?` on the generic key decides whether `send()` needs query params at all. The `?` on each field decides which
fields are needed when they are passed.

| Generic              | `send()`                                  | Use it for                         |
| -------------------- | ----------------------------------------- | ---------------------------------- |
| `queryParams: Q`     | Requires `queryParams`                    | Endpoints that need a filter       |
| `queryParams?: Q`    | Accepts `queryParams` or nothing          | Lists with optional filters        |
| no `queryParams` key | Accepts no query params                   | Endpoints without a query string   |

```ts title="src/app.ts"
// error-next-line
await getUsers.send(); // queryParams are required

// error-next-line
await getUsers.send({ queryParams: { role: "guest" } }); // "guest" is not a role

const admins = getUsers.setQueryParams({ role: "admin" });
await admins.send(); // already set, send() takes no query params
```

In an SDK schema with `RequestModel`, write optional query params as `queryParams?: Q | null`.

---

## Reuse the query params type

`ExtractQueryParamsType` reads the type back, for example to build filters from the URL:

```ts title="src/filters.ts"
import type { ExtractQueryParamsType } from "@hyper-fetch/core";

type Filters = ExtractQueryParamsType<typeof getUsers>;

export const readFilters = (search: URLSearchParams): Filters => ({
  role: search.get("role") === "admin" ? "admin" : "member",
  search: search.get("q") ?? undefined,
});
```
