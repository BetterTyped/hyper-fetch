# Request extractors

A request carries its response, payload, params, query params and error types. Extractors read them back, so components
and helpers can use the same types without repeating them. This guide shows the common extractors and the full list.

:::secondary What you'll learn

1. How to read a request's types with **extractors**.
2. How to type **helpers and components** with them.
3. Which **extractors** are available.

:::

---

## Read types from a request

```ts title="src/api/users.ts"
import type {
  ExtractErrorType,
  ExtractParamsType,
  ExtractPayloadType,
  ExtractResponseType,
} from "@hyper-fetch/core";

export const updateUser = client.createRequest<{
  response: { id: number; name: string; email: string };
  payload: { name?: string; email?: string };
  error: { fields: { email?: string[] } };
}>()({ endpoint: "/users/:userId", method: "PATCH" });

type UpdatedUser = ExtractResponseType<typeof updateUser>; // { id; name; email }
type UserChanges = ExtractPayloadType<typeof updateUser>; // { name?; email? }
// { userId: string | number }
type UserParams = ExtractParamsType<typeof updateUser>;
// local error | global error
type UpdateError = ExtractErrorType<typeof updateUser>;
```

## Type helpers with them

The extracted types follow the request: change the request's generics and every helper updates.

```ts title="src/users.ts"
const renderUser = (user: UpdatedUser) =>
  console.log(`${user.name} <${user.email}>`);

const reportError = (error: UpdateError) => {
  if (error instanceof Error) console.error(error.message);
  else if ("fields" in error) console.error(error.fields.email);
  else console.error(error.message);
};

export async function saveUser(params: UserParams, changes: UserChanges) {
  const { data, error } = await updateUser.send({ params, payload: changes });

  if (data) renderUser(data);
  else if (error) reportError(error);
}
```

To accept any request of a given shape, rather than one request, use a generic constraint. See
[extend request](/docs/guides/typescript/extend).

## All extractors

Every extractor takes the type of a request, as in `ExtractResponseType<typeof getUser>`.

| Extractor                    | Returns                                                         |
| ---------------------------- | --------------------------------------------------------------- |
| `ExtractResponseType`        | The `response` type, the type of `data`                         |
| `ExtractPayloadType`         | The `payload` type                                              |
| `ExtractParamsType`          | The URL params, from the endpoint                               |
| `ExtractQueryParamsType`     | The `queryParams` type                                          |
| `ExtractErrorType`           | The local error joined with the client's global error           |
| `ExtractLocalErrorType`      | The request's own `error` type                                  |
| `ExtractGlobalErrorType`     | The client's global error                                       |
| `ExtractEndpointType`        | The endpoint string literal                                     |
| `ExtractClientType`          | The client the request was created from                         |
| `ExtractAdapterType`         | The client's adapter                                            |
| `ExtractHasParamsType`, `ExtractHasPayloadType`, `ExtractHasQueryParamsType` | `true` when the value is already set |
| `RequestResponseType`        | The whole object `send()` resolves with                         |
| `RequestSendOptionsType`     | The options `send()` accepts                                    |
