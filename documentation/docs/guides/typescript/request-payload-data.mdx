# Request payload type

The `payload` generic types the body a request sends. Every caller of the request is then checked against it, and the
payload is required at `send()` until it is set. For encoding and `FormData`, see the
[payload guide](/docs/guides/core/basics/payload).

:::secondary What you'll learn

1. How to type the payload with the **`payload` generic**.
2. What TypeScript **catches** when the payload is wrong or missing.
3. How to **reuse** the type with `ExtractPayloadType`.

:::

---

## Type the payload

```ts title="src/api/users.ts"
type CreateUserPayload = { name: string; email: string; age?: number };

export const createUser = client.createRequest<{
  response: User;
  payload: CreateUserPayload;
}>()({ endpoint: "/users", method: "POST" });

const { data } = await createUser.send({ payload: { name: "Ann", email: "ann@example.com" } });
```

---

## What TypeScript catches

```ts title="src/app.ts"
// error-next-line
await createUser.send(); // payload is required

// error-next-line
await createUser.send({ payload: { name: "Ann" } }); // email is missing

const prepared = createUser.setPayload({ name: "Ann", email: "ann@example.com" });
await prepared.send(); // payload is set, send() takes no payload
```

A request with a payload set no longer accepts another one in `send()`. Start from the original request to send a
different payload. For an endpoint whose body is optional, make the fields optional, such as
`payload: { from?: string }`, and send `payload: {}` when there is nothing to pass.

---

## Reuse the payload type

`ExtractPayloadType` reads the payload type from a request, for forms and helpers:

```ts title="src/user-form.ts"
import type { ExtractPayloadType } from "@hyper-fetch/core";

type UserForm = ExtractPayloadType<typeof createUser>; // CreateUserPayload

export const submitUser = (values: UserForm) => createUser.send({ payload: values });
```

`setPayloadMapper` does not change the payload type: callers keep passing the typed object, and the mapper converts it
right before sending.
