The `init` command creates the API folder and an `api.json` file that tells [`generate`](/docs/cli/commands/generate)
where to write the SDK and how to import it.

```bash
npx @hyper-fetch/cli@latest init --yes
```

:::tip Purpose

1.  **Pick the output folder** once, in `api.json`.
2.  **Detect path aliases** from `tsconfig.json`, so imports match your project.
3.  **Prepare** the project for `generate`.

:::

---

## What it creates

Without `--yes`, `init` asks for the main directory (`src`, `app` or another path) and the API folder name (`api`).
With `--yes` it uses `src` and `api`. It creates the folder and writes `api.json` in the working directory:

```text title="Project after init"
my-app
├── api.json
├── package.json
├── tsconfig.json
└── src
    └── api
```

```json title="api.json"
{
  "tsx": true,
  "aliases": {
    "api": "@/api",
    "hooks": "@/hooks",
    "ui": "@/components/ui",
    "components": "@/components",
    "lib": "@/lib"
  }
}
```

- **Aliases** come from `compilerOptions.paths` in `tsconfig.json`. With `"@/*": ["./src/*"]` the API folder is
  `@/api`. Without a matching path alias, the value is the folder relative to `baseUrl`, such as `src/api`.
- **`api`** is the folder `generate` writes to. The other aliases are reserved for future commands.
- **`tsx: true`** gives a `.ts` file when the file name has no extension, `false` a `.js` file.

Running `init` again keeps the values of an existing `api.json` and fills in missing ones.

---

## Flags

| Flag     | Alias | Default           | Description                                    |
| -------- | ----- | ----------------- | ---------------------------------------------- |
| `--yes`  | `-y`  | `false`           | Skip the prompts and use `src` and `api`       |
| `--cwd`  | `-c`  | current directory | Working directory with `package.json`          |
| `--help` | `-h`  |                   | Print the flags                                |

You can skip `init`: when `api.json` is missing, `generate` runs it with `--yes` defaults first.

---

:::secondary Summary

- `init` creates the API folder and `api.json`. `--yes` uses `src/api`.
- `aliases.api` decides where `generate` writes, resolved through your tsconfig paths.

:::
