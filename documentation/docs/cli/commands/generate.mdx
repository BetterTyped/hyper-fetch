The `generate` command reads an OpenAPI 3 or Swagger JSON schema and writes one TypeScript file with the model types,
the types of every operation, an `SdkSchema` and a `createSdk` factory you call with your own client.

```bash
npx @hyper-fetch/cli@latest generate --template openapi --url ./openapi.json \
  --fileName pets.sdk.ts --overwrite
```

:::tip Purpose

1.  **Generate** typed requests for every operation of your schema.
2.  **Model types** from `components.schemas`, exported as the `Components` namespace.
3.  **Regenerate** without prompts in scripts and CI.

:::

---

## From schema to SDK

For this schema, with `Pet`, `NewPet` and `Error` in `components.schemas`:

```json title="openapi.json (excerpt)"
{
  "paths": {
    "/pets": {
      "get": {
        "operationId": "listPets",
        "parameters": [
          { "name": "limit", "in": "query", "schema": { "type": "integer" } }
        ],
        "responses": {
          "200": {
            "content": {
              "application/json": {
                "schema": {
                  "type": "array",
                  "items": { "$ref": "#/components/schemas/Pet" }
                }
              }
            }
          }
        }
      },
      "post": {
        "operationId": "createPet",
        "requestBody": {
          "content": {
            "application/json": {
              "schema": { "$ref": "#/components/schemas/NewPet" }
            }
          }
        },
        "responses": {
          "201": {
            "content": {
              "application/json": {
                "schema": { "$ref": "#/components/schemas/Pet" }
              }
            }
          },
          "422": {
            "content": {
              "application/json": {
                "schema": { "$ref": "#/components/schemas/Error" }
              }
            }
          }
        }
      }
    },
    "/pets/{petId}": {
      "get": {
        "operationId": "getPet",
        "parameters": [
          {
            "name": "petId",
            "in": "path",
            "required": true,
            "schema": { "type": "integer" }
          }
        ],
        "responses": {
          "200": {
            "content": {
              "application/json": {
                "schema": { "$ref": "#/components/schemas/Pet" }
              }
            }
          },
          "404": {
            "content": {
              "application/json": {
                "schema": { "$ref": "#/components/schemas/Error" }
              }
            }
          }
        }
      }
    }
  }
}
```

`generate` writes `src/api/pets.sdk.ts` (the folder comes from `api.json`). Its end, as generated:

```ts title="src/api/pets.sdk.ts (excerpt)"
export type ListPetsQueryParams = Paths.ListPets.QueryParameters;
export type ListPetsErrorType = undefined;
export type ListPetsResponseType = Paths.ListPets.Responses.$200;

export type CreatePetRequestBody = Paths.CreatePet.RequestBody;
export type CreatePetErrorType = Paths.CreatePet.Responses.$422;
export type CreatePetResponseType = Paths.CreatePet.Responses.$201;

export type GetPetPathParams = Paths.GetPet.PathParameters;
export type GetPetErrorType = Paths.GetPet.Responses.$404;
export type GetPetResponseType = Paths.GetPet.Responses.$200;

export type SdkSchema = {
  pets: {
    $get: RequestModel<{
      response: ListPetsResponseType;
      queryParams?: ListPetsQueryParams;
      error: ListPetsErrorType;
      endpoint: "/pets";
    }>;
    $post: RequestModel<{
      response: CreatePetResponseType;
      payload: CreatePetRequestBody;
      error: CreatePetErrorType;
      endpoint: "/pets";
    }>;
    $petId: {
      $get: RequestModel<{
        response: GetPetResponseType;
        error: GetPetErrorType;
        endpoint: "/pets/:petId";
      }>;
    };
  };
};

export const createSdk = <Client extends ClientInstance>(
  client: Client,
  options?: Parameters<typeof coreCreateSdk>[1] | undefined,
) => {
  return coreCreateSdk<Client, SdkSchema>(client, {
    ...options,
    pathSegments: { ...sdkPathSegments, ...options?.pathSegments },
  });
};
```

Above it are the `Components` and `Paths` namespaces with the model and operation types, and `sdkPathSegments`.

| Schema                        | Generated                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------ |
| `components.schemas.Pet`      | `Components.Schemas.Pet`                                                       |
| 2xx responses                 | `<Op>ResponseType`, a union, `any` when none is described                      |
| 4xx and 5xx responses         | `<Op>ErrorType`, a union, `undefined` when none is described                   |
| `requestBody`                 | `<Op>RequestBody`, the `payload`                                               |
| Query parameters              | `<Op>QueryParams`, required when any query param is required                   |
| Path `/pets/{petId}`          | Endpoint `"/pets/:petId"`, keys `pets.$petId`                                  |
| HTTP method                   | `$get`, `$post`, `$put`, `$patch`, `$delete` on the path                       |
| Path `/user-profiles`         | Key `userProfiles`. camelCase segments such as `findByStatus` go in `sdkPathSegments` |

Type names come from the `operationId`. Operations without one get names built from the method and path.

## Use the generated SDK

```ts title="src/api/index.ts"
import { createClient } from "@hyper-fetch/core";
import { createSdk } from "./pets.sdk";

export const client = createClient({ url: "https://api.example.com" });

export const sdk = createSdk(client).$configure({
  "*": { retry: 2 },
});

const { data, error } = await sdk.pets.$petId.$get.send({ params: { petId: 1 } });
await sdk.pets.$post.send({ payload: { name: "Rex" } });
```

Do not edit the generated file, the next run replaces it. Put defaults in `$configure`, and auth or interceptors on the
client. See [SDK](/docs/core/sdk).

## Flags

| Flag          | Alias | Default                       | Description                                                                 |
| ------------- | ----- | ----------------------------- | --------------------------------------------------------------------------- |
| `--template`  | `-t`  | asked                         | `openapi` or `swagger`, both use the same generator                         |
| `--url`       | `-u`  | asked                         | An `http(s)` URL, or a local `.json` path relative to `--cwd`               |
| `--fileName`  | `-f`  | asked, `api-<template>.sdk.ts` | File name inside the `api` folder from `api.json`                           |
| `--overwrite` | `-o`  | asked when the file exists    | Replace an existing file without asking                                     |
| `--cwd`       | `-c`  | current directory             | Working directory with `package.json` and `tsconfig.json`                    |
| `--help`      | `-h`  |                               | Print the flags                                                             |

There is no `--output` flag, and `-o` means `--overwrite`. The folder comes from `aliases.api` in `api.json`, see
[`init`](/docs/cli/commands/init). The interactive prompt accepts URLs only, so pass local files with `--url`.

## Regenerate in CI

Pass `-t`, `-u`, `-f` and `-o` so the command never prompts, and fail the build when the committed SDK is stale:

```json title="package.json"
{
  "scripts": {
    "api:generate": "hyper-fetch generate -t openapi -u ./openapi.json -f pets.sdk.ts -o",
    "api:check": "npm run api:generate && git diff --exit-code -- src/api/pets.sdk.ts"
  }
}
```

Run `tsc` after it: calls that no longer match the API fail to compile.

## Troubleshooting

| Problem                             | Cause and fix                                                                   |
| ----------------------------------- | ------------------------------------------------------------------------------- |
| `unknown option '--output'`         | There is no such flag. Set the folder in `api.json`, the name with `-f`         |
| `Failed to load tsconfig.json`      | Add a `tsconfig.json` to the working directory                                  |
| `Cannot reach the server`           | The schema URL is unreachable. Download the schema and pass the local path      |
| Protected schema URL                | The CLI sends no auth headers. Download it with your credentials first          |
| YAML schema                         | Only JSON is parsed. Convert the file first                                     |
| File written to another folder      | `aliases.api` resolves through tsconfig `paths`. Check the alias and the paths  |

---

:::secondary Summary

- `generate` writes types, an `SdkSchema` and `createSdk` into the `api` folder from `api.json`.
- Pass `-t`, `-u`, `-f` and `-o` in scripts so it never prompts.
- Never edit the output: configure with `$configure` and the client, then regenerate.

:::
