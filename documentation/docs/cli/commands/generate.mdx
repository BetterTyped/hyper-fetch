The `generate` command reads your OpenAPI or Swagger JSON schema and writes one TypeScript file with typed requests and
data models, plus a `createSdk` factory you call with your own Hyper-Fetch client.

```bash
npx @hyper-fetch/cli@latest generate
```

---

:::tip Purpose

By using the code generator, you can:

1.  **Automatically generate** a ready-to-use SDK for your Hyper-Fetch client.
2.  **Create typed requests** for all your API endpoints.
3.  **Define data models** based on your schema components.
4.  **Boost productivity** by eliminating manual setup for API integration.

:::

---

## Usage

You can use it in two ways - by going through wizard or passing individual arguments.

Remember to initialize a project first - this way hyper-fetch will be able to find the project's configuration and
generate files in the correct location.

:::info Initialize a project

If you don't have a project yet, you can initialize one with the [`init`](./init) command.

```bash
npx @hyper-fetch/cli@latest init
```

:::

1. ### Wizard

To use the wizard, run the following command:

```bash
npx @hyper-fetch/cli@latest generate
```

It will guide you through the process of generating the typed requests and data models.

2. ### Custom arguments

You can also pass individual arguments to the command. Which is useful for the scripts.

```bash
npx @hyper-fetch/cli@latest generate --template openapi --url https://petstore3.swagger.io/api/v3/openapi.json --fileName petstore.sdk.ts
```

## Example

```bash
npx @hyper-fetch/cli@latest generate --template openapi --url https://petstore3.swagger.io/api/v3/openapi.json --fileName petstore.sdk.ts
```

This writes `petstore.sdk.ts` to the `api` directory configured in `api.json` (`src/api` by default). Each path becomes a
nested key and each HTTP method a `$`-prefixed key on it, so `GET /store/inventory` is `sdk.store.inventory.$get`.

Kebab-case segments become camelCase keys: `GET /user-profiles` is `sdk.userProfiles.$get`. Segments that are already
camelCase keep their spelling in the url: `GET /pet/findByStatus` is `sdk.pet.findByStatus.$get` and calls
`/pet/findByStatus`. The generated file exports these segments as `sdkPathSegments` and passes them to `createSdk` as
the `pathSegments` option. Segments you pass yourself take precedence.

Then to use generated SDK you can do the following:

```ts
import { createClient } from "@hyper-fetch/core";
// This is the path to the generated SDK
// highlight-start
import { createSdk } from "./path-to-my-sdk";
// highlight-end

const client = createClient({
  url: "http://localhost:3000",
});
// Export the sdk
// highlight-start
export const sdk = createSdk(client);
// highlight-end

// code-editor-split

import { sdk } from "./client";

// Use the sdk
// highlight-start
const { data, error } = await sdk.store.inventory.$get.send();
// highlight-end

if (error) {
  console.error(error);
}

console.log(data);
```

## Available arguments

| Flag                      | Description                                                                          |
| ------------------------- | ------------------------------------------------------------------------------------ |
| `-t`, `--template <name>` | Schema template: `openapi` or `swagger`                                              |
| `-u`, `--url <source>`    | Schema source: an `http(s)` URL or a local `.json` path relative to `--cwd`          |
| `-f`, `--fileName <name>` | Name of the generated file. It is written to the `api` directory from `api.json`     |
| `-o`, `--overwrite`       | Overwrite an existing file without asking                                            |
| `-c`, `--cwd <dir>`       | Working directory (default: the current directory)                                   |
| `-h`, `--help`            | Print the available arguments                                                        |

Every value you leave out is asked for interactively. Pass `-t`, `-u`, `-f` and `-o` in scripts and CI so the command
never prompts.

:::info Output location

There is no `--output` flag. The folder comes from `aliases.api` in `api.json`, and `--fileName` only sets the file name.

:::

Run the following command to print the arguments in your terminal:

```bash
npx @hyper-fetch/cli@latest generate --help
```
