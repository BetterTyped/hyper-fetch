`@hyper-fetch/cli` generates a typed HyperFetch [SDK](/docs/core/sdk) from an OpenAPI 3 or Swagger JSON schema. You
get one TypeScript file with every model and operation type and a `createSdk` factory, and you keep your own client for
the base URL, auth and plugins.

```bash
npx @hyper-fetch/cli@latest generate --template openapi --url ./openapi.json \
  --fileName api.sdk.ts
```

```ts title="src/api/index.ts"
import { createClient } from "@hyper-fetch/core";
import { createSdk } from "./api.sdk"; // generated

export const client = createClient({ url: "https://api.example.com" });
export const sdk = createSdk(client);

// GET /pet/:petId, typed from the schema
const { data, error } = await sdk.pet.$petId.$get.send({ params: { petId: 1 } });
```

:::tip Purpose

1.  **Generate** typed requests and models from your OpenAPI or Swagger schema.
2.  **Configure once** with an `api.json` file that decides where generated files go.
3.  **Regenerate** in scripts and CI, so types follow the API.

:::

---

## Commands

| Command                                     | What it does                                                         |
| ------------------------------------------- | -------------------------------------------------------------------- |
| [`init`](/docs/cli/commands/init)           | Creates `api.json` and the API folder                                |
| [`generate`](/docs/cli/commands/generate)   | Writes the SDK file from a schema URL or a local JSON file           |

Run `npx @hyper-fetch/cli@latest` without a command to pick one from a menu. Every value you leave out is asked for
interactively, so pass all flags in scripts. The binary is called `hyper-fetch` when the package is installed:

```bash npm2yarn2pnpm
npm install --save-dev @hyper-fetch/cli
```

Pin the version in your project, so regenerated output does not change between CLI releases.

---

## Requirements

- A `package.json` and a `tsconfig.json` in the working directory (`--cwd`).
- A schema in JSON. Convert YAML before generating.
- `@hyper-fetch/core` in your dependencies, since the generated file imports it.

---

## Automatic setup

When `api.json` is missing, `generate` runs `init` with its defaults first: it creates `api.json` and a `src/api` folder,
then writes the SDK there. Run [`init`](/docs/cli/commands/init) yourself to pick another folder.

---

:::secondary Summary

- `generate` turns an OpenAPI or Swagger JSON schema into one typed SDK file.
- `init` writes `api.json`, which decides the output folder. `generate` creates it when missing.
- Call the generated `createSdk(client)` with your own client.

:::
