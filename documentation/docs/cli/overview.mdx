# HyperFetch CLI

<Lead>

**Turn your OpenAPI schema into a typed SDK with one command.** `@hyper-fetch/cli` writes one TypeScript file with
every model and operation, and you keep your own client for the base URL, auth and plugins.

</Lead>

```bash title="terminal"
npx @hyper-fetch/cli@latest generate --template openapi --url ./openapi.json \
  --fileName api.sdk.ts
```

```ts title="src/api/index.ts"
import { createClient } from "@hyper-fetch/core";
import { createSdk } from "./api.sdk"; // generated

export const client = createClient({ url: "https://api.example.com" });
export const sdk = createSdk(client);

// GET /pet/:petId, typed from the schema
const { data, error } = await sdk.pet.$petId.$get.send({
  params: { petId: 1 },
});
```

## Commands

<Tiles>
  <Tile title="generate" icon="terminal" meta="command" to="/docs/cli/commands/generate">
    Writes the SDK file from a schema URL or a local JSON file.
  </Tile>
  <Tile title="init" icon="wrench" meta="command" to="/docs/cli/commands/init">
    Creates `api.json` and the folder generated files go to.
  </Tile>
</Tiles>

`generate` runs `init` with its defaults when `api.json` is missing, so one command is enough to start. Run the CLI
without a command to pick one from a menu. Every flag you leave out is asked for in a prompt, so pass all of them in
scripts and CI.

---

## Before you start

- A `package.json` and a `tsconfig.json` in the working directory (`--cwd`).
- A schema in JSON. Convert YAML before generating.
- `@hyper-fetch/core` in your dependencies, since the generated file imports it.

Install the CLI as a dev dependency to pin its version, so regenerated output does not change between releases. The
binary is then called `hyper-fetch`.

```bash npm2yarn2pnpm
npm install --save-dev @hyper-fetch/cli
```
