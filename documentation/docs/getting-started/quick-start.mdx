# HyperFetch quick start

Each package has its own quick start. Pick the one for your stack. All of them start from the same client and request,
so you can add the others later without rewriting anything.

```ts title="api.ts"
import { createClient } from "@hyper-fetch/core";

export const client = createClient({ url: "https://api.example.com" });

export const getUsers = client.createRequest<{
  response: { id: number; name: string }[];
}>()({
  endpoint: "/users",
});
```
