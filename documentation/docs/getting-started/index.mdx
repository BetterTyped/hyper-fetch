# HyperFetch

<Lead>

**Define each endpoint once, send it anywhere.** HyperFetch turns your API into typed requests, and handles the
cache, retries, queues and offline mode for you, in the browser, on the server and in native apps.

</Lead>

```ts title="api.ts"
import { createClient } from "@hyper-fetch/core";

const client = createClient({ url: "https://api.example.com" });

export const getUser = client.createRequest<{ response: User }>()({
  endpoint: "/users/:userId",
});

// Typed params, typed data. send() never throws.
const { data, error } = await getUser.send({ params: { userId: 1 } });
```

In React, the same request goes into a hook: `useFetch(getUser.setParams({ userId: 1 }))`.
