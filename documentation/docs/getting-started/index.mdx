**HyperFetch** is a TypeScript framework for request-based and realtime communication. You define each endpoint once as
a typed request, and the client behind it caches, deduplicates, retries, queues and resumes it after going offline, in
the browser, on the server, in React Native or in Electron.

```ts title="api.ts"
import { createClient } from "@hyper-fetch/core";

type User = { id: number; name: string };

// One client per backend: base URL, adapter, cache and queues
export const client = createClient({ url: "https://api.example.com" });

// One typed request per endpoint, defined once
export const getUser = client.createRequest<{ response: User }>()({
  endpoint: "/users/:userId",
});

// `:userId` is a required, typed param. send() resolves, it never throws.
const { data, error, status } = await getUser.send({ params: { userId: 1 } });
```

In React the same request goes into a hook: `useFetch(getUser.setParams({ userId: 1 }))`.

## What you get

- **Typed requests**: response, payload, params, query params and errors are checked when you send, see
  [Request](/docs/core/request).
- **Cache**: responses are stored by key with `staleTime` and `cacheTime`, see [Cache](/docs/core/cache).
- **Request control**: deduplication, cancelation, queues, retries and offline handling, see
  [Dispatcher](/docs/core/dispatcher).
- **Any transport**: the built-in fetch adapter, or Axios, GraphQL, Firebase, tRPC and oRPC, see
  [Adapter](/docs/core/adapter).
- **Realtime**: WebSocket and SSE listeners and emitters typed the same way, see [Sockets](/docs/sockets/overview).
- **Typed SDKs**: describe a whole API as one schema, or [generate it from OpenAPI](/docs/cli/overview), see
  [SDK](/docs/core/sdk).
- **Devtools**: inspect requests, cache and queues in [HyperFlow](/docs/hyper-flow).

## Where to start

1. [Install](/docs/getting-started/installation) the packages you need.
2. Follow a [quick start](/docs/getting-started/quick-start): plain TypeScript, React or sockets.
3. Open a runnable example, such as [Basic data fetching](/examples/getting-started/basic) or
   [Vanilla TypeScript](/examples/getting-started/vanilla).
4. Read the [guides](/docs/guides/getting-started) when you need a specific task, like auth, pagination or offline.
