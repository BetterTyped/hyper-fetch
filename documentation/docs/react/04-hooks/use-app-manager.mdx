# useAppManager

`useAppManager` returns the online and focus state of a [client's](/docs/core/client)
[`AppManager`](/docs/core/managers) and lets you change them. Use it for offline banners, or to set the state yourself
in environments without browser events.

:::tip Purpose

1. **Online state**: render offline banners from `isOnline`.
2. **Focus state**: know whether the window or app is in the foreground.
3. **Manual control**: `setOnline` and `setFocused` update the state for the whole client.

:::

---

## Usage

```tsx title="components/offline-banner.tsx"
import { useAppManager } from "@hyper-fetch/react";
import { client } from "./api/client";

function OfflineBanner() {
  const { isOnline } = useAppManager(client);

  if (isOnline) return null;
  return <p>You are offline. Changes will be sent when you reconnect.</p>;
}
```

---

## Options

The hook takes only the `client`.

---

## Returns

(@import react useAppManager type=returns)

---

## Set the state yourself

`setOnline` and `setFocused` change the state of the client's `AppManager`, not only of this hook. Requests react to
it: offline requests wait for the network, and hooks with `refetchOnFocus` or `refetchOnReconnect` fetch when the state
changes back.

```tsx title="Simulate offline mode"
const { isOnline, setOnline } = useAppManager(client);

<button onClick={() => setOnline(!isOnline)}>{isOnline ? "Go offline" : "Go online"}</button>;
```

In the browser the `AppManager` listens to window events. In [React Native](/docs/react/environments/react-native) and
[Electron](/docs/react/environments/electron), connect it to the platform's events when you create the client.

---

:::secondary Summary

1. `useAppManager(client)` returns `isOnline`, `isFocused`, `setOnline` and `setFocused`.
2. The setters change the state for the whole client.

:::
