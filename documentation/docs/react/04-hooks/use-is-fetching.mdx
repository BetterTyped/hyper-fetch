# useIsFetching

`useIsFetching` returns how many requests are being sent right now by the fetch dispatcher of a
[client](/docs/core/client): the ones from `useFetch`, `useCache` and `client.fetchDispatcher`. `useIsSubmitting` counts
the submit dispatcher (`useSubmit`). Use them for global loading and saving indicators.

:::tip Purpose

1. **Global indicators**: one spinner or progress bar for the whole app.
2. **Scoped counts**: count only the requests of one query or a custom filter.

:::

---

## Usage

```tsx title="components/global-spinner.tsx"
import { useIsFetching, useIsSubmitting } from "@hyper-fetch/react";
import { client } from "./api/client";

function GlobalSpinner() {
  const fetching = useIsFetching(client);
  const submitting = useIsSubmitting(client);

  if (!fetching && !submitting) return null;
  return <Spinner label={submitting ? "Saving..." : "Loading..."} />;
}
```

## Options

(@import react UseIsFetchingOptionsType type=returns)

---

## Returns

A `number`: the requests being sent at the moment. Queued requests waiting for their turn and requests waiting for the
network are not counted. The hook re-renders only when the number changes, and returns `0` during server rendering.

---

## Count part of the app

Filter by `queryKey` (exact string or RegExp) or with a `predicate`.

```tsx title="Scoped counts"
const usersFetching = useIsFetching(client, { queryKey: getUsers.queryKey });
const adminFetching = useIsFetching(client, { queryKey: /admin/ });
const uploading = useIsSubmitting(client, { predicate: (request) => request.endpoint.startsWith("/files") });
```

---

:::secondary Summary

1. `useIsFetching` counts running fetch requests, `useIsSubmitting` running submits.
2. Filter with `queryKey` or `predicate`.

:::
