# useStream

`useStream` sends a request with the fetch adapter's `streaming` option and reads the response body chunk by chunk. Use
it to show LLM output or long text as it arrives, or to collect a binary download. For server-pushed events over
WebSocket or SSE, use [`useListener`](/docs/react/sockets/use-listener).

:::tip Purpose

1. **Text streaming**: `text` grows as each chunk arrives, decoded as UTF-8.
2. **Binary streaming**: raw `Uint8Array` chunks for downloads.
3. **Lifecycle control**: `start()`, `abort()` and `reset()`.

:::

---

## Usage

```tsx title="components/ai-chat.tsx"
import { useStream } from "@hyper-fetch/react";
import { chatCompletion } from "./api/ai";

function AiChat({ prompt }: { prompt: string }) {
  const { text, streaming, done, start, abort } = useStream(
    chatCompletion.setPayload({ prompt }),
  );

  return (
    <div>
      <p className="whitespace-pre-wrap">{text}</p>
      {done && <p>Complete</p>}
      <button type="button" onClick={start} disabled={streaming}>
        Ask
      </button>
      <button type="button" onClick={abort} disabled={!streaming}>
        Stop
      </button>
    </div>
  );
}
```

The hook sends the request with `streaming: true` for you, so the request itself needs no extra setup.

---

## Options

| Option      | Type      | Default | Description                     |
| ----------- | --------- | ------- | ------------------------------- |
| `autoStart` | `boolean` | `false` | Start the stream on mount.      |

---

## Returns

| Property    | Type                    | Description                                                                                  |
| ----------- | ----------------------- | -------------------------------------------------------------------------------------------- |
| `text`      | `string`                | Text of all chunks so far, decoded as UTF-8.                                                 |
| `chunks`    | `Uint8Array[]`          | Raw binary chunks.                                                                           |
| `streaming` | `boolean`               | The stream is being read.                                                                    |
| `done`      | `boolean`               | Every chunk has been read.                                                                   |
| `error`     | error type or `null`    | Error of the request or of reading the stream.                                               |
| `extra`     | adapter extra or `null` | Response metadata, such as headers.                                                          |
| `status`    | `number \| null`        | HTTP status of the response.                                                                 |
| `start`     | `() => void`            | Send the request and read the stream.                                                        |
| `abort`     | `() => void`            | Stop the request, or the body once it is being read. The text received so far stays.         |
| `reset`     | `() => void`            | Stop like `abort()` and clear the state, so a new stream can start.                          |

---

## Start on mount

With `autoStart: true` the stream starts when the component mounts. Unmounting aborts a running stream, whether it was
started by `autoStart` or by `start()`.

```tsx title="Live log"
function BuildLog() {
  const { text, streaming } = useStream(getBuildLog, { autoStart: true });

  return <pre>{streaming ? `${text}...` : text}</pre>;
}
```

---

## Stream again

`reset()` aborts a running stream and clears `text`, `chunks` and the flags. Call `start()` after it to stream again.

```tsx title="Regenerate an answer"
const { text, done, start, reset } = useStream(
  chatCompletion.setPayload({ prompt }),
);

const regenerate = () => {
  reset();
  start();
};
```

---

## Responses that are not streams

When the response body is not a `ReadableStream`, for example a JSON error from the server, the hook does not fail. It
sets `text` to the data (passed through `JSON.stringify` when it is not a string), leaves `chunks` empty and sets `done`
to `true`.

---

:::secondary Summary

1. `useStream` sends the request with `streaming: true` and reads the body chunk by chunk.
2. Use `text` for LLM and text output, `chunks` for binary data.
3. `autoStart` starts on mount; unmounting aborts the stream.

:::
