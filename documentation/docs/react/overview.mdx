# React overview

<Lead>

**Pass a request to a hook, get typed data, error and loading state back.** No query keys or fetcher functions: the
request you defined with [core](/docs/core/overview) already knows its endpoint, types and cache key.

</Lead>

```tsx title="users.tsx"
import { useFetch } from "@hyper-fetch/react";

import { getUsers } from "./api/users";

export const Users = () => {
  // highlight-next-line
  const { data, loading, error } = useFetch(getUsers);

  if (loading && !data) return <p>Loading...</p>;
  if (error) return <p>{error.message}</p>;

  return <ul>{data?.map((user) => <li key={user.id}>{user.name}</li>)}</ul>;
};
```

`data` is typed as `User[] | null` from the request, so the hook needs no generics. The hooks need React 18 or later.

## Global defaults

Hooks work without a provider. Add `<Provider>` when every hook should share options, such as refetching when the
window regains focus. Options passed to a hook always win. The
[config provider guide](/docs/guides/react/basics/config-provider) shows the setup.
