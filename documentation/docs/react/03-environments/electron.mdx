# Electron

HyperFetch runs in Electron's renderer process like in a [browser](/docs/react/environments/browser), with no setup.
Browser events can be unreliable in Electron, so you can send online and focus state from the main process instead and
feed it to the client's [`AppManager`](/docs/core/managers).

:::tip Purpose

1. **Works as is** in the renderer process.
2. **Accurate online state**: check real connectivity in the main process.
3. **Window focus**: use `BrowserWindow` events instead of DOM events.

:::

---

## 1. Send the state from the main process

`is-online` checks real connectivity; `BrowserWindow` reports focus. Send both to the renderer over IPC.

```ts title="main/app-state.ts"
import type { BrowserWindow } from "electron";
import isOnline from "is-online";

export const sendAppState = (window: BrowserWindow) => {
  let online: boolean | null = null;

  setInterval(async () => {
    const next = await isOnline();
    if (next !== online) window.webContents.send("app:online", (online = next));
  }, 5000);

  window.on("focus", () => window.webContents.send("app:focused", true));
  window.on("blur", () => window.webContents.send("app:focused", false));
};
```

---

## 2. Expose it in the preload script

With `contextIsolation` on, the renderer cannot import `ipcRenderer`. Expose a small subscribe function instead.

```ts title="preload.ts"
import { contextBridge, ipcRenderer } from "electron";

contextBridge.exposeInMainWorld("appState", {
  subscribe: (channel: "app:online" | "app:focused", callback: (value: boolean) => void) => {
    const listener = (_event: unknown, value: boolean) => callback(value);
    ipcRenderer.on(channel, listener);
    return () => ipcRenderer.removeListener(channel, listener);
  },
});
```

---

## 3. Connect the client

```ts title="renderer/api/client.ts"
import { AppManager, Client } from "@hyper-fetch/core";

export const client = new Client({
  url: "https://api.example.com",
  appManager: () =>
    new AppManager({
      onlineEvent: (setOnline) => window.appState.subscribe("app:online", setOnline),
      focusEvent: (setFocused) => window.appState.subscribe("app:focused", setFocused),
    }),
});
```

Each event returns the unsubscribe function, so the listeners are removed when `client.clear()` runs. Declare
`window.appState` in a `.d.ts` file to type it.

---

:::secondary Summary

1. HyperFetch works in the renderer with no setup.
2. For accurate state, send connectivity and focus from the main process over IPC.
3. Pass them to the client through `onlineEvent` and `focusEvent` of a custom `AppManager`.

:::
