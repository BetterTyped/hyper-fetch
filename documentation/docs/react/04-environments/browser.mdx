# Browser

HyperFetch needs no setup in the browser. The client's [`AppManager`](/docs/core/managers) listens to window and
document events to know when the app is online and focused, which drives offline requests, `refetchOnFocus` and
`refetchOnReconnect`.

:::tip Purpose

1. **No setup**: online and focus state come from browser events.
2. **Server rendering**: the same client works on the server without browser events.
3. **Customizable**: replace the events with your own when the defaults do not fit.

:::

---

## Default events

| State   | Initial value         | Updated by                                                       |
| ------- | --------------------- | ---------------------------------------------------------------- |
| Online  | `navigator.onLine`    | `online` and `offline` window events                             |
| Focused | `true`                | `focus` and `blur` window events, and document `visibilitychange` |

Read or change the state in components with [`useAppManager`](/docs/react/hooks/use-app-manager).

---

## Server rendering

The client detects where it runs: `"client"` mode in the browser, `"server"` mode elsewhere. On the server the cache
stores only scoped requests, so concurrent renders never share data, and hooks do not send requests. Fetch on the server
and pass the responses to the browser with [`Hydrate`](/docs/react/hydrate).

---

## Replace the events

Pass your own `AppManager` to the client to change where the state comes from, for example to treat a hidden tab as
focused.

```ts title="api/client.ts"
import { AppManager, Client } from "@hyper-fetch/core";

export const client = new Client({
  url: "https://api.example.com",
  appManager: () =>
    new AppManager({
      // Only window focus counts; document visibility is ignored
      focusEvent: (setFocused) => {
        const onFocus = () => setFocused(true);
        const onBlur = () => setFocused(false);
        window.addEventListener("focus", onFocus);
        window.addEventListener("blur", onBlur);

        return () => {
          window.removeEventListener("focus", onFocus);
          window.removeEventListener("blur", onBlur);
        };
      },
    }),
});
```

Return a cleanup function from `focusEvent` and `onlineEvent` so the listeners are removed when `client.clear()` runs.

---

:::secondary Summary

1. In the browser, online and focus state come from window and document events with no setup.
2. On the server, hooks do not fetch; use `Hydrate` for server data.
3. Pass a custom `AppManager` to change the events.

:::
