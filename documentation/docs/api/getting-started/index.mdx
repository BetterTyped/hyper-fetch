# API reference

The API reference lists every class, function, type and variable each HyperFetch package exports, with signatures,
parameters and return types. It is generated from the TypeScript source and its TSDoc comments on every docs build, so
it always matches the published code.

Use it to look up an exact signature. For how and when to use something, start from the docs and guides instead.

Every package has its own section in the sidebar, grouped by kind, such as classes, functions, hooks, types and
variables.

## Reading an entry

- **Classes** list their constructor, properties and methods. Setters on `Request` return a new request.
- **Functions** list their parameters and return type.
- **Types** show the full definition, with a description of each property where the source has one.

For concepts and examples, see the [core overview](/docs/core/overview) and the
[guides](/docs/guides/getting-started).
