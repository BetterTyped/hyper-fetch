A **mock** replaces the adapter for one request instance. The request still goes through the dispatcher, the cache and
every event, so loading states, progress, retries and cancelation behave as with a real server. Use mocks for tests,
stories and building a UI before the API exists.

:::tip Purpose

1. **Return fake data or errors** with full type safety.
2. **Simulate timing**: request and response time, progress and timeouts.
3. **Keep the lifecycle**: events, cache writes and aborts work as usual.

:::

```tsx live
const getNotes = client.createRequest()({
  endpoint: "/notes",
});

getNotes.setMock(
  // Called on every send
  ({ request, requestId }) => {
    return {
      data: { items: [{ text: "This is mocked note" }] },
      status: 200,
    };
  },
  // Timing and progress
  { requestTime: 500, responseTime: 500, totalUploaded: 1000, totalDownloaded: 1000 },
);

const response = await getNotes.send();
console.log(response);
```

## Return data or errors

The mock callback receives `{ request, requestId }` and returns a response with a `status` and `data` or `error`. It can
be async. Return an `error` to simulate a failure.

```ts
const getUser = client.createRequest<{ response: User }>()({ endpoint: "/users/:userId" });

getUser.setMock(({ request }) => {
  if (request.params?.userId === 0) {
    return { error: new Error("Not found"), status: 404 };
  }
  return { data: { id: Number(request.params?.userId), name: "Ann" }, status: 200 };
});
```

## Simulate timing, progress and timeouts

The second argument sets how the mock behaves over time. The request phase emits upload progress, the response phase
download progress.

(@import core MockerConfigType type=returns&display=table)

```tsx live title="Timeout"
const request = client.createRequest()({
  endpoint: "shared-base-endpoint",
});

request.setMock(() => ({ data: { mocking: "is fun" }, status: 200 }), {
  requestTime: 2000,
  responseTime: 2000,
  // Resolves with a timeout error after 1s
  timeout: 1000,
});

const response = await request.send();
console.log(response);
```

Aborting works as with a real request: `send()` resolves with an abort error.

```tsx live title="Abort"
const request = client.createRequest()({
  endpoint: "some-endpoint",
});

request.setMock(() => ({ data: { mocking: "is fun" }, status: 200 }), {
  requestTime: 1000,
  responseTime: 1000,
});

const response = await request.send({
  onRequestStart: () => {
    request.abort();
  },
});
console.log(response.error);
```

## Mock setters change the instance

`setMock`, `clearMock` and `setMockingEnabled` change the request they are called on, unlike the other setters, which
return a clone. Clones made later copy the mock, clones made earlier do not. Set the mock on the base request first.

```ts
const getFirstUser = getUser.setParams({ userId: 1 }); // made before the mock: not mocked

getUser.setMock(() => ({ data: { id: 2, name: "Mocked" }, status: 200 }));

getUser.setParams({ userId: 2 }); // made after the mock: mocked
```

Every SDK property access creates a new request, so keep a reference: `const getUsers = sdk.users.$get`.

## Mock a whole SDK

`$configure` with function values attaches mocks to SDK endpoints. It returns a new SDK, so the original stays
unmocked.

```ts title="test/sdk.ts"
import type { RequestInstance } from "@hyper-fetch/core";
import { sdk } from "../src/api/sdk";

export const testSdk = sdk.$configure({
  "users.$get": (request: RequestInstance) => request.setMock(() => ({ data: [{ id: 1, name: "John" }], status: 200 })),
  "posts.$get": (request: RequestInstance) => request.setMock(() => ({ data: [], status: 200 })),
});
```

See [SDK configuration](/docs/core/sdk#configure-endpoints-with-configure).

---

## Turn mocks off

| Call                                    | Effect                                                        |
| --------------------------------------- | ------------------------------------------------------------- |
| `request.clearMock()`                   | Removes the mock from the request                             |
| `request.setMockingEnabled(false)`      | Keeps the mock but sends real requests until turned back on   |
| `client.setEnableGlobalMocking(false)`  | Ignores the mocks of every request of the client              |

---

:::secondary Summary

- `setMock(callback, config)` replaces the adapter for one request and keeps the whole lifecycle.
- Return `data` or `error` with a `status`. Set timing, progress and `timeout` in the config.
- Mock setters change the instance. Set them before deriving clones, and keep SDK requests in a variable.

:::
