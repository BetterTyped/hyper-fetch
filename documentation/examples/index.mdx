Every example is a small, complete app you can run in the browser, open in StackBlitz or CodeSandbox, or copy to your
machine. Each one focuses on a single idea and explains what it shows and how it works.

:::tip How to use the examples

1. **Read the page** to see what the example shows and which parts of HyperFetch it uses.
2. **Press Run example** to start it in your browser, or open it in StackBlitz or CodeSandbox to edit it.
3. **Copy it locally** with `npx tiged BetterTyped/hyper-fetch/examples/<group>/<name> my-app`.

:::

The examples live in the [`examples/`](https://github.com/BetterTyped/hyper-fetch/tree/main/examples) folder of the
repository. They are built and type-checked against the current source on every change, so the code you see here works
with the latest release.
