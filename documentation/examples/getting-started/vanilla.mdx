A todo list and a lookup form built with plain DOM code. `@hyper-fetch/core` does not need React or any other framework:
you create a client, describe requests, and call `send()`.

<Example files={{ "src/api.ts": api, "src/main.ts": main }} />

:::tip What it shows

1. **`createClient` and `createRequest`** work the same with or without a UI framework.
2. **`send()`** takes typed `params` and `queryParams` and returns a promise with the response.
3. **The response object** carries `data`, `error`, `success`, `status` and timestamps for every call.
4. **Errors resolve, they do not throw.** A 404 comes back as a response with a typed `error`.

:::

---

## How it works

1. `api.ts` creates one client with `createClient({ url })` and two requests. `getTodo` also sets the `error` generic,
   so `response.error` is typed as the `{ message }` body dummyjson returns for a missing todo.
2. `main.ts` writes a static HTML skeleton and fills it with `textContent`, so nothing from the API is parsed as HTML.
3. `loadTodos()` calls `getTodos.send({ queryParams: { limit: 5 } })` on start. The values passed to `send()` apply to
   that call only.
4. The lookup form calls `getTodo.send({ params: { todoId } })`. `:todoId` in the endpoint makes `params` required, so
   TypeScript flags a call without it.
5. Every field of the response is printed: `success` and `status`, then `data` or `error`, and the time between
   `requestTimestamp` and `responseTimestamp`. Try id `9999` to see a 404 come back as a normal response.

```ts
const response = await getTodo.send({ params: { todoId } });
// highlight-next-line
if (response.error) console.log(response.status, response.error.message);
```

`send()` also accepts lifecycle callbacks such as `onRequestStart`, `onDownloadProgress` and `onResponse` when you need
to react before the promise settles.

:::note When to use it

- Scripts, web components or apps built with a framework that has no HyperFetch bindings.
- Code that runs outside components, such as route loaders, workers or Node scripts.

:::
