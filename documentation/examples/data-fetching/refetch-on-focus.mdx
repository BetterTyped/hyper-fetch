A random todo that is fetched again when you come back to the tab, leave it, or get your connection back. Each option
has a switch, and a log prints every focus or network event followed by the request it caused.

<Example files={{ "src/api.ts": api, "src/App.tsx": app }} />

:::tip What it shows

1. **`refetchOnFocus`** refetches when the window or tab gets focus again.
2. **`refetchOnBlur`** refetches when the user leaves the window or tab.
3. **`refetchOnReconnect`** refetches when the network comes back.
4. **The app manager** (`client.appManager`) is the source of these events, and `useAppManager` reads and sets its
   state.

:::

---

## How it works

1. `App` keeps the three options in state and passes them straight to `useFetch(getRandomTodo, options)`. The hook reads
   the current value when an event arrives, so the switches take effect at once.
2. The client's app manager listens to the browser's `visibilitychange`, `focus`, `blur`, `online` and `offline` events
   and emits `focus`, `blur`, `online` and `offline`. The hook refetches on the events its options allow.
3. A `useEffect` subscribes to `client.appManager.events` to log the cause, and the hook's `onRequestStart` callback
   logs the request that follows it.
4. `useAppManager(client)` returns `isFocused` and `isOnline` for the status line, plus `setFocused` and `setOnline`.
   The "Simulate" and "Go offline" buttons call them, which emits the same events as the browser would. That makes
   reconnects easy to try without unplugging anything.
5. Switching tabs can fire both `visibilitychange` and `focus`, so the log may show two focus events. Deduplication of
   GET requests still sends only one request.

```tsx
const { data } = useFetch(getRandomTodo, {
  // highlight-next-line
  refetchOnFocus: true,
  refetchOnBlur: false,
  refetchOnReconnect: true,
});
```

All three options are `false` by default. Each refetch also restarts the `refreshTime` timer when polling is on.

:::note When to use it

- Data that other people or other tabs change, such as inboxes, carts or shared boards.
- Apps used on phones, where users switch apps and lose the network often.

:::
