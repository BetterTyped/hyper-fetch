# @hyper-fetch/testing

**Internal. Not published, not supported, not part of the public API.**

Mock servers and helpers that the HyperFetch monorepo uses in its own specs: `createHttpMockingServer`,
`createGraphqlMockingServer`, `createWebsocketMockingServer`, `createSseMockingServer`, the e2e servers, `sleep`,
`waitForConnection` and the type assertions.

Do not mention this package in the README, documentation, blog, landing page, examples or social posts. Users mock
requests with `request.setMock()` from `@hyper-fetch/core`.
