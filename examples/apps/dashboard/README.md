# Dashboard

An admin dashboard with KPI cards from parallel requests, a polled live number, a server-sorted table, an offline banner
and errors kept inside each widget.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/apps/dashboard)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/apps/dashboard)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/apps/dashboard)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/apps/dashboard hyper-fetch-dashboard
cd hyper-fetch-dashboard
npm install
npm run dev
```
