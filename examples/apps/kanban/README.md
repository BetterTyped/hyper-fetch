# Kanban board

A kanban board with native drag and drop, optimistic moves with rollback, a sync status and changes shared between tabs.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/apps/kanban)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/apps/kanban)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/apps/kanban)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/apps/kanban hyper-fetch-kanban
cd hyper-fetch-kanban
npm install
npm run dev
```
