# Rick and Morty explorer

Explore the Rick and Morty API with React Router: search and pages in the URL, dependent requests, prefetch on hover and
a cache reused on every visit.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/apps/rick-and-morty)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/apps/rick-and-morty)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/apps/rick-and-morty)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/apps/rick-and-morty hyper-fetch-rick-and-morty
cd hyper-fetch-rick-and-morty
npm install
npm run dev
```
