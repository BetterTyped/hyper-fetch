# Shop

A small shop with React Router: catalog with categories, search and infinite scroll, an optimistic cart persisted in
localStorage, and a validated checkout.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/apps/shop)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/apps/shop)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/apps/shop)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/apps/shop hyper-fetch-shop
cd hyper-fetch-shop
npm install
npm run dev
```
