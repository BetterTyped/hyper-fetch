# TodoMVC

TodoMVC with a Hono API in the same Vite app: filters in the URL, optimistic toggles and edits, clear completed, and
todos stored on the server.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/apps/todomvc)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/apps/todomvc)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/apps/todomvc)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/apps/todomvc hyper-fetch-todomvc
cd hyper-fetch-todomvc
npm install
npm run dev
```
