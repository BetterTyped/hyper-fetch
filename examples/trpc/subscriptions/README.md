# tRPC subscriptions

A live chat on tRPC subscriptions, streamed over Server-Sent Events into useListener with typed events and resume
support.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/trpc-subscriptions)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/trpc/subscriptions)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/trpc/subscriptions)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/trpc/subscriptions hyper-fetch-trpc-subscriptions
cd hyper-fetch-trpc-subscriptions
npm install
npm run dev
```
