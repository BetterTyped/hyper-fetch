# tRPC

A tRPC router served by Hono and a React client that calls it through HyperFetch with types inferred from the router.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/trpc)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/trpc/basic)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/trpc/basic)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/trpc/basic hyper-fetch-trpc-basic
cd hyper-fetch-trpc-basic
npm install
npm run dev
```
