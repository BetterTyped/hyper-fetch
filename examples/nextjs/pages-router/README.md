# Next.js Pages Router

Fetch in getServerSideProps, dehydrate the responses and hydrate them into HyperFetch hooks with one Hydrate in \_app.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/frameworks/nextjs-pages-router)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/nextjs/pages-router)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/nextjs/pages-router)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/nextjs/pages-router hyper-fetch-nextjs-pages-router
cd hyper-fetch-nextjs-pages-router
npm install
npm run dev
```
