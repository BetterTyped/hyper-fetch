# Next.js streaming

Stream slow server data into a Next.js App Router page section by section with Suspense, and hydrate each section into
HyperFetch hooks.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/frameworks/nextjs-streaming)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/nextjs/streaming)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/nextjs/streaming)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/nextjs/streaming hyper-fetch-nextjs-streaming
cd hyper-fetch-nextjs-streaming
npm install
npm run dev
```
