# Next.js App Router

Fetch on the server in a Next.js App Router page and hydrate the response into the client cache.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/frameworks/nextjs-app-router)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/nextjs/app-router)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/nextjs/app-router)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/nextjs/app-router hyper-fetch-nextjs-app-router
cd hyper-fetch-nextjs-app-router
npm install
npm run dev
```
