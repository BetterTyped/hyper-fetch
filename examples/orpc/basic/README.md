# oRPC

A contract-first oRPC API on Hono and a React client typed from the contract, with Dates and typed errors kept end to
end.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/orpc)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/orpc/basic)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/orpc/basic)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/orpc/basic hyper-fetch-orpc-basic
cd hyper-fetch-orpc-basic
npm install
npm run dev
```
