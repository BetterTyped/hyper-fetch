# oRPC event iterators

Stream job progress from an oRPC async generator into useListener over an HTTP event stream, with event ids and typed
events.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/orpc-event-iterator)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/orpc/event-iterator)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/orpc/event-iterator)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/orpc/event-iterator hyper-fetch-orpc-event-iterator
cd hyper-fetch-orpc-event-iterator
npm install
npm run dev
```
