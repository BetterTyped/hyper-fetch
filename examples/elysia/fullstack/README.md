# Elysia fullstack

An Elysia API on Node.js and a React client whose requests, query params and error bodies are typed from the Elysia
routes.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/elysia)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/elysia/fullstack)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/elysia/fullstack)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/elysia/fullstack hyper-fetch-elysia-fullstack
cd hyper-fetch-elysia-fullstack
npm install
npm run dev
```
