# Dependent requests

Fetch a user first, then load their posts and todos only once the user id is known.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/dependent-requests)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/dependent-requests)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/dependent-requests)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/dependent-requests hyper-fetch-dependent-requests
cd hyper-fetch-dependent-requests
npm install
npm run dev
```
