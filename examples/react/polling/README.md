# Polling

Refetch data on an interval with refresh and refreshTime, and pause polling in background tabs.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/polling)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/polling)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/polling)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/polling hyper-fetch-polling
cd hyper-fetch-polling
npm install
npm run dev
```
