# Mocking

Build a screen before its backend exists with setMock: mocked data, latency, errors and timeouts.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/mocking)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/mocking)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/mocking)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/mocking hyper-fetch-mocking
cd hyper-fetch-mocking
npm install
npm run dev
```
