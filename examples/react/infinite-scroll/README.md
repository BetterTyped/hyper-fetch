# Infinite scroll

Load the next page of products as you scroll, with useInfiniteFetch and an IntersectionObserver.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/infinite-scroll)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/infinite-scroll)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/infinite-scroll)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/infinite-scroll hyper-fetch-infinite-scroll
cd hyper-fetch-infinite-scroll
npm install
npm run dev
```
