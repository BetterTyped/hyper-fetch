# React Router

React Router loaders prefetch through HyperFetch so components read from the cache, and an action saves edits and
updates the cache.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/frameworks/react-router)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/react-router)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/react-router)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/react-router hyper-fetch-react-router
cd hyper-fetch-react-router
npm install
npm run dev
```
