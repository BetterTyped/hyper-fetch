# Testing

Test a component that fetches and saves data with Vitest, Testing Library and HyperFetch mocks.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/getting-started/testing)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/testing)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/testing)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/testing hyper-fetch-testing
cd hyper-fetch-testing
npm install
npm run dev
```

## Run the tests

```bash
npm test
```
