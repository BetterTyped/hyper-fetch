# Payload validation

Validate the payload with zod in a request mapper, show field errors in the form, and send nothing when the data is
invalid.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/payload-validation)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/payload-validation)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/payload-validation)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/payload-validation hyper-fetch-payload-validation
cd hyper-fetch-payload-validation
npm install
npm run dev
```
