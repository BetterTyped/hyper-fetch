# Prefetching

Prefetch product details on hover with request.send(), so opening them shows cached data at once.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/prefetching)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/prefetching)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/prefetching)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/prefetching hyper-fetch-prefetching
cd hyper-fetch-prefetching
npm install
npm run dev
```
