# Refetch on focus

Refetch when the window gets focus, loses it or the network comes back, with a log of every trigger.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/refetch-on-focus)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/refetch-on-focus)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/refetch-on-focus)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/refetch-on-focus hyper-fetch-refetch-on-focus
cd hyper-fetch-refetch-on-focus
npm install
npm run dev
```
