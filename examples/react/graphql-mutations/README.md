# GraphQL mutations

Create, update and delete with GraphQL mutations and write each result into the cached query instead of fetching it
again.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/graphql-mutations)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/graphql-mutations)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/graphql-mutations)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/graphql-mutations hyper-fetch-graphql-mutations
cd hyper-fetch-graphql-mutations
npm install
npm run dev
```
