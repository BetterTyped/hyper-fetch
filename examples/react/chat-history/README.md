# Chat history

A chat that opens at the newest messages and loads older ones with fetchPreviousPage as you scroll up, keeping your
place.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/chat-history)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/chat-history)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/chat-history)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/chat-history hyper-fetch-chat-history
cd hyper-fetch-chat-history
npm install
npm run dev
```
