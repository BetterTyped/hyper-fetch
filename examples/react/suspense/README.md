# Suspense

Load data with React Suspense and handle failed requests in an error boundary with throwOnError.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/suspense)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/suspense)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/suspense)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/suspense hyper-fetch-suspense
cd hyper-fetch-suspense
npm install
npm run dev
```
