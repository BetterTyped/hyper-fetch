# Data table

A product table with server-side sorting, search and pagination that keeps the previous rows on screen while the next
ones load.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/data-table)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/data-table)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/data-table)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/data-table hyper-fetch-data-table
cd hyper-fetch-data-table
npm install
npm run dev
```
