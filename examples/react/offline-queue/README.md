# Offline queue

Requests made offline wait in the queue and are sent in order when the app is back online.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/offline/offline-queue)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/offline-queue)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/offline-queue)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/offline-queue hyper-fetch-offline-queue
cd hyper-fetch-offline-queue
npm install
npm run dev
```
