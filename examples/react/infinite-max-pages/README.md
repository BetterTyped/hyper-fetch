# Infinite list with max pages

An infinite list that keeps only three pages with useInfiniteFetch maxPages and loads dropped pages again when you
scroll back.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/infinite-max-pages)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/infinite-max-pages)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/infinite-max-pages)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/infinite-max-pages hyper-fetch-infinite-max-pages
cd hyper-fetch-infinite-max-pages
npm install
npm run dev
```
