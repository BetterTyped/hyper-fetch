# Typed SDK

Describe an API once as a typed schema and call it through createSdk with useFetch and useSubmit.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/getting-started/sdk)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/sdk)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/sdk)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/sdk hyper-fetch-sdk
cd hyper-fetch-sdk
npm install
npm run dev
```
