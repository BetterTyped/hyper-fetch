# Pagination

Page through products with query params, keep the previous page on screen and prefetch the next one.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/pagination)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/pagination)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/pagination)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/pagination hyper-fetch-pagination
cd hyper-fetch-pagination
npm install
npm run dev
```
