# File upload

Upload a file as FormData with useSubmit, follow each phase of the request with progress bars and cancel it with abort.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/mutations/file-upload)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/file-upload)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/file-upload)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/file-upload hyper-fetch-file-upload
cd hyper-fetch-file-upload
npm install
npm run dev
```
