# Custom hooks

Wrap requests in your own typed hooks, usePosts, usePost and useRenamePost, so components stay small.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/getting-started/custom-hooks)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/custom-hooks)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/custom-hooks)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/custom-hooks hyper-fetch-custom-hooks
cd hyper-fetch-custom-hooks
npm install
npm run dev
```
