# IndexedDB persistence

Persist large responses in IndexedDB with the cache lazyStorage, and show them from disk while the API is asked again.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/offline/indexeddb-persistence)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/indexeddb-persistence)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/indexeddb-persistence)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/indexeddb-persistence hyper-fetch-indexeddb-persistence
cd hyper-fetch-indexeddb-persistence
npm install
npm run dev
```
