# Optimistic updates

Toggle and add todos instantly with setOptimistic, and roll the change back when the server rejects it.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/mutations/optimistic-updates)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/optimistic-updates)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/optimistic-updates)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/optimistic-updates hyper-fetch-optimistic-updates
cd hyper-fetch-optimistic-updates
npm install
npm run dev
```
