# Authentication

Log in, attach the token to every request with onAuth and refresh it on a 401 with onError.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/authentication)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/authentication)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/authentication)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/authentication hyper-fetch-authentication
cd hyper-fetch-authentication
npm install
npm run dev
```
