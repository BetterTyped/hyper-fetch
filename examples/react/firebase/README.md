# Firebase

A Firestore guestbook where every read and write is a HyperFetch request, with query constraints, typed documents and
errors in the response.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/firebase)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/firebase)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/firebase)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/firebase hyper-fetch-firebase
cd hyper-fetch-firebase
npm install
cp .env.example .env.local # then fill in your Firebase config
npm run dev
```
