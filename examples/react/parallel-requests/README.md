# Parallel requests

Load several independent requests at once, each with its own loading state, and show a global indicator with
useIsFetching.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/parallel-requests)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/parallel-requests)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/parallel-requests)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/parallel-requests hyper-fetch-parallel-requests
cd hyper-fetch-parallel-requests
npm install
npm run dev
```
