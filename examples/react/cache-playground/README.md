# Cache playground

Change staleTime, cacheTime, retry and refetchOnFocus with sliders and watch the cache and the network react.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/getting-started/cache-playground)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/cache-playground)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/cache-playground)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/cache-playground hyper-fetch-cache-playground
cd hyper-fetch-cache-playground
npm install
npm run dev
```
