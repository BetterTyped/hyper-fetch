# Custom retry

Retry only network errors and 5xx answers, with exponential backoff and jitter, and log every attempt.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/custom-retry)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/custom-retry)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/custom-retry)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/custom-retry hyper-fetch-custom-retry
cd hyper-fetch-custom-retry
npm install
npm run dev
```
