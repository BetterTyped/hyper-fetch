# Timeouts

Set a timeout per request with the adapter options, show a clear timeout state, and retry with the same or a longer
limit.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/timeouts)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/timeouts)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/timeouts)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/timeouts hyper-fetch-timeouts
cd hyper-fetch-timeouts
npm install
npm run dev
```
