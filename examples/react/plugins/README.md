# Plugins

Write a logging plugin and a metrics plugin that see every request of the client, and show their output live.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/plugins)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/plugins)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/plugins)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/plugins hyper-fetch-plugins
cd hyper-fetch-plugins
npm install
npm run dev
```
