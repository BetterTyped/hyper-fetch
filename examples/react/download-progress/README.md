# Download progress

Download a file with a live percentage, speed and time left from onDownloadProgress, then save it from a Blob.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/download-progress)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/download-progress)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/download-progress)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/download-progress hyper-fetch-download-progress
cd hyper-fetch-download-progress
npm install
npm run dev
```
