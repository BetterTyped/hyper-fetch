# AI chat

Stream a model answer token by token from a local Hono server with useStream, with stop and regenerate.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/realtime/ai-chat)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/ai-chat)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/ai-chat)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/ai-chat hyper-fetch-ai-chat
cd hyper-fetch-ai-chat
npm install
npm run dev
```
