# Undo delete

Delete a todo optimistically, offer Undo for five seconds and send the request only if nobody undoes it, with rollback
on failure.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/mutations/undo-delete)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/undo-delete)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/undo-delete)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/undo-delete hyper-fetch-undo-delete
cd hyper-fetch-undo-delete
npm install
npm run dev
```
