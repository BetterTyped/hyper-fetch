# Resume after reload

Keep offline mutations in a persistent dispatcher queue, so they survive a page reload and are sent once online.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/offline/resume-after-reload)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/resume-after-reload)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/resume-after-reload)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/resume-after-reload hyper-fetch-resume-after-reload
cd hyper-fetch-resume-after-reload
npm install
npm run dev
```
