# Tab sync

Send cache changes to every open tab with a BroadcastChannel, so all tabs show the same data without refetching.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/caching/tab-sync)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/tab-sync)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/tab-sync)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/tab-sync hyper-fetch-tab-sync
cd hyper-fetch-tab-sync
npm install
npm run dev
```
