# Fetch on click

Send a request only when the user asks: useFetch with disabled, or request.send() for a one-off call.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/fetch-on-click)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/fetch-on-click)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/fetch-on-click)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/fetch-on-click hyper-fetch-fetch-on-click
cd hyper-fetch-fetch-on-click
npm install
npm run dev
```
