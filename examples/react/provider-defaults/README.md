# Provider defaults

Set useFetch options once for the whole app with the React Provider, and override them per hook.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/getting-started/provider-defaults)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/provider-defaults)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/provider-defaults)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/provider-defaults hyper-fetch-provider-defaults
cd hyper-fetch-provider-defaults
npm install
npm run dev
```
