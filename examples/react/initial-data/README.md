# Initial data

Show a product's details at once with initialResponse taken from the list, then replace them with the server response.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/caching/initial-data)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/initial-data)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/initial-data)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/initial-data hyper-fetch-initial-data
cd hyper-fetch-initial-data
npm install
npm run dev
```
