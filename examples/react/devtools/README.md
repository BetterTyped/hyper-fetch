# Devtools

Connect a client to the HyperFlow devtools with the devtools plugin and inspect requests, cache and queues.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/devtools)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/devtools)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/devtools)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/devtools hyper-fetch-devtools
cd hyper-fetch-devtools
npm install
npm run dev
```
