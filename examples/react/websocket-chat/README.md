# WebSocket chat

A chat over WebSocket with useListener and useEmitter, connection state and reconnects.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/realtime/websocket-chat)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/websocket-chat)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/websocket-chat)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/websocket-chat hyper-fetch-websocket-chat
cd hyper-fetch-websocket-chat
npm install
npm run dev
```
