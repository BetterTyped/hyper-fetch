# URL filters

Keep search, sort and page in the URL query string and turn them into typed query params, with working back and forward.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/url-filters)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/url-filters)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/url-filters)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/url-filters hyper-fetch-url-filters
cd hyper-fetch-url-filters
npm install
npm run dev
```
