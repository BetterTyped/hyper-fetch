# Streaming

Render a streamed HTTP response chunk by chunk with useStream, the way chat apps show an LLM answer.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/realtime/streaming)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/streaming)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/streaming)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/streaming hyper-fetch-streaming
cd hyper-fetch-streaming
npm install
npm run dev
```
