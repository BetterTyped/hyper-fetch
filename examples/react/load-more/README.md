# Load more

Load pages on demand with a Load more button, start in the middle of a list and see where each page begins.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/load-more)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/load-more)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/load-more)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/load-more hyper-fetch-load-more
cd hyper-fetch-load-more
npm install
npm run dev
```
