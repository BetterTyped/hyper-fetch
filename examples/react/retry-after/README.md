# Retry-After

Handle 429 Too Many Requests in one client interceptor that waits as long as the Retry-After header says and sends the
request again.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/retry-after)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/retry-after)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/retry-after)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/retry-after hyper-fetch-retry-after
cd hyper-fetch-retry-after
npm install
npm run dev
```
