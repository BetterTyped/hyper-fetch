# Live cache updates

Load a list once with useFetch and keep its cache current with server-sent events from a local Hono server.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/realtime/live-cache-updates)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/live-cache-updates)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/live-cache-updates)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/live-cache-updates hyper-fetch-live-cache-updates
cd hyper-fetch-live-cache-updates
npm install
npm run dev
```
