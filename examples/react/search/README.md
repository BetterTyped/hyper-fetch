# Search as you type

Search products while typing and send one request per pause with the bounce option of useFetch.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/search)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/search)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/search)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/search hyper-fetch-search
cd hyper-fetch-search
npm install
npm run dev
```
