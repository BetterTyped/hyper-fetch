# CRUD

Create, read, update and delete todos, and write each server response into the cached list instead of refetching it.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/mutations/crud)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/crud)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/crud)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/crud hyper-fetch-crud
cd hyper-fetch-crud
npm install
npm run dev
```
