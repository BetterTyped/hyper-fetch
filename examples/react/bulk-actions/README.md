# Bulk actions

Complete or delete many todos at once, one at a time or in parallel, with a progress bar and a result for every row.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/mutations/bulk-actions)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/bulk-actions)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/bulk-actions)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/bulk-actions hyper-fetch-bulk-actions
cd hyper-fetch-bulk-actions
npm install
npm run dev
```
