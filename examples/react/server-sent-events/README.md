# Server-sent events

Listen to a live server-sent events stream with the SSE adapter and useListener, with pause and resume.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/realtime/server-sent-events)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/server-sent-events)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/server-sent-events)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/server-sent-events hyper-fetch-server-sent-events
cd hyper-fetch-server-sent-events
npm install
npm run dev
```
