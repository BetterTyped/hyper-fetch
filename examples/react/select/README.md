# Select

Read different parts of one cached response with the select option, and re-render only when that part changes.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/data-fetching/select)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/select)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/select)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/select hyper-fetch-select
cd hyper-fetch-select
npm install
npm run dev
```
