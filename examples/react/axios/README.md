# Axios

Send HyperFetch requests with axios through the Axios adapter, with axios options and errors passed through.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/axios)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/axios)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/axios)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/axios hyper-fetch-axios
cd hyper-fetch-axios
npm install
npm run dev
```
