# Notifications

Live notifications pushed over server-sent events from a local Hono server, with an unread badge, mark as read and a
capped list.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/realtime/notifications)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/notifications)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/notifications)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/notifications hyper-fetch-notifications
cd hyper-fetch-notifications
npm install
npm run dev
```
