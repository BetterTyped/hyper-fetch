# Stale time

See staleTime, cacheTime and the revalidate option at work, with a live view of what is fresh, stale or removed from the
cache.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/caching/stale-time)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/stale-time)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/stale-time hyper-fetch-stale-time
cd hyper-fetch-stale-time
npm install
npm run dev
```
