# Deduplication

Let many callers that ask for the same data at once share one network request with deduplicate.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/deduplication)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/deduplication)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/deduplication)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/deduplication hyper-fetch-deduplication
cd hyper-fetch-deduplication
npm install
npm run dev
```
