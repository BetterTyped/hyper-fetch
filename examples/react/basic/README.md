# Basic data fetching

Fetch a list and its details with `useFetch`, typed requests and a shared cache.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/getting-started/basic)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/basic)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/basic)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/basic hyper-fetch-basic
cd hyper-fetch-basic
npm install
npm run dev
```
