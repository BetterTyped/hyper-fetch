# Cache persistence

Persist the cache to localStorage so a reload shows data at once, without a request.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/offline/cache-persistence)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/cache-persistence)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/cache-persistence)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/cache-persistence hyper-fetch-cache-persistence
cd hyper-fetch-cache-persistence
npm install
npm run dev
```
