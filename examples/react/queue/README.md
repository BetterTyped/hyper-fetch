# Queue

Send messages one at a time with queued requests, and start, pause, stop or remove them with useQueue.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/queue)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/queue)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/queue)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/queue hyper-fetch-queue
cd hyper-fetch-queue
npm install
npm run dev
```
