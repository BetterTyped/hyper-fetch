# Offline first

Persist both the cache (IndexedDB) and the request queue (localStorage), so the app opens with data and keeps changes
made offline across reloads.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/offline/offline-first)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/offline-first)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/offline-first)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/offline-first hyper-fetch-offline-first
cd hyper-fetch-offline-first
npm install
npm run dev
```
