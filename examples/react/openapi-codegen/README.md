# OpenAPI codegen

Generate typed HyperFetch requests from the Swagger Petstore OpenAPI spec with @hyper-fetch/cli and use them in React.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/openapi-codegen)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/openapi-codegen)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/openapi-codegen)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/openapi-codegen hyper-fetch-openapi-codegen
cd hyper-fetch-openapi-codegen
npm install
npm run dev
```
