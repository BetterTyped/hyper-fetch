# Response mapping

Validate API responses with zod and map them to the app shape with setResponseMapper.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/response-mapping)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/response-mapping)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/response-mapping)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/response-mapping hyper-fetch-response-mapping
cd hyper-fetch-response-mapping
npm install
npm run dev
```
