# Invalidation

Invalidate cached lists after a mutation so every useFetch that shows them fetches fresh data.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/mutations/invalidation)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/invalidation)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/invalidation)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/invalidation hyper-fetch-invalidation
cd hyper-fetch-invalidation
npm install
npm run dev
```
