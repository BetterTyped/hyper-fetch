# Cache updates

Edit cached data with client.cache.update and watch every component that reads it, through useFetch or useCache, update
at once.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/caching/cache-updates)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/cache-updates)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/cache-updates)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/cache-updates hyper-fetch-cache-updates
cd hyper-fetch-cache-updates
npm install
npm run dev
```
