# Typed errors

Give each endpoint its own error type on top of the global one, and narrow the union in the UI to show the right
message.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/request-control/typed-errors)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/typed-errors)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/typed-errors)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/typed-errors hyper-fetch-typed-errors
cd hyper-fetch-typed-errors
npm install
npm run dev
```
