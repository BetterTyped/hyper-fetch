# Drag to reorder

Reorder a list with native drag and drop, update it optimistically and move the item back when the save fails.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/mutations/drag-reorder)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/drag-reorder)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/drag-reorder)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/drag-reorder hyper-fetch-drag-reorder
cd hyper-fetch-drag-reorder
npm install
npm run dev
```
