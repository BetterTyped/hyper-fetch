# TanStack Router

TanStack Router loaders fill the HyperFetch cache, and hovering a link prefetches the next page before you click.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/frameworks/tanstack-router)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/tanstack-router)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/tanstack-router)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/tanstack-router hyper-fetch-tanstack-router
cd hyper-fetch-tanstack-router
npm install
npm run dev
```
