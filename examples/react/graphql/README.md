# GraphQL

Query a GraphQL API with the GraphQL adapter: typed queries, variables and per-variable caching.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/graphql)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/graphql)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/graphql)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/graphql hyper-fetch-graphql
cd hyper-fetch-graphql
npm install
npm run dev
```
