# Shared state

Share a cart between distant components through the HyperFetch cache with useCache and client.cache.update, without
props or context.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/caching/shared-state)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/shared-state)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/shared-state)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/shared-state hyper-fetch-shared-state
cd hyper-fetch-shared-state
npm install
npm run dev
```
