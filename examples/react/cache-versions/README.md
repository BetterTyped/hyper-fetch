# Cache versions

Bump the cache version with a release, so persisted data in an old shape is dropped instead of breaking the new code.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/offline/cache-versions)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/react/cache-versions)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/react/cache-versions)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/react/cache-versions hyper-fetch-cache-versions
cd hyper-fetch-cache-versions
npm install
npm run dev
```
