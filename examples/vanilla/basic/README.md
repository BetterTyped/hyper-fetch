# Vanilla TypeScript

Send typed requests from plain TypeScript and read the response object, no framework needed.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/getting-started/vanilla)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/vanilla/basic)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/vanilla/basic)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/vanilla/basic hyper-fetch-vanilla-basic
cd hyper-fetch-vanilla-basic
npm install
npm run dev
```
