# HyperFetch on the server

A Node.js script that sends typed requests, runs them in parallel and retries failures, with code that also runs in Bun,
Deno and Workers.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/server-runtimes)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/node/server)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/node/server)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/node/server hyper-fetch-node-server
cd hyper-fetch-node-server
npm install
npm run dev
```
