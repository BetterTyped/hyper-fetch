# DB realtime feed

A team feed whose rows stay live: REST loads them, socket events insert, update and delete them, in this tab and every
other one.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/db/realtime-feed)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/db/realtime-feed)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/db/realtime-feed)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/db/realtime-feed hyper-fetch-db-realtime-feed
cd hyper-fetch-db-realtime-feed
npm install
npm run dev
```
