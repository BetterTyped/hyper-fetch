# DB todos

A todo list on a db collection: one live query, filters that run locally and writes that show at once and revert on
failure.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/db/todos)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/db/todos)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/db/todos)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/db/todos hyper-fetch-db-todos
cd hyper-fetch-db-todos
npm install
npm run dev
```
