# DB infinite feed

An infinite feed with useLiveInfiniteQuery: pages load on demand from a cursor API and new posts still arrive live at
the top.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/db/infinite-feed)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/db/infinite-feed)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/db/infinite-feed)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/db/infinite-feed hyper-fetch-db-infinite-feed
cd hyper-fetch-db-infinite-feed
npm install
npm run dev
```
