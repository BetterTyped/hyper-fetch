# DB issue tracker

An issue tracker on the db: server and local filters, joined assignees, a list and detail view that share rows, and
explain() showing each query plan.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/db/issue-tracker)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/db/issue-tracker)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/db/issue-tracker)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/db/issue-tracker hyper-fetch-db-issue-tracker
cd hyper-fetch-db-issue-tracker
npm install
npm run dev
```
