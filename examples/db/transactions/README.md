# DB transactions

Move cards between boards with db.transaction: several writes are kept or reverted together, as one request or in order.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/db/transactions)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/db/transactions)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/db/transactions)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/db/transactions hyper-fetch-db-transactions
cd hyper-fetch-db-transactions
npm install
npm run dev
```
