# Astro

Fetch on the server in an Astro page and hydrate the response into a React island that uses HyperFetch hooks.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/frameworks/astro)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/astro/ssr)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/astro/ssr)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/astro/ssr hyper-fetch-astro-ssr
cd hyper-fetch-astro-ssr
npm install
npm run dev
```
