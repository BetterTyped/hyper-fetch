# Hono fullstack

A Hono API and a React client in one Vite app, with requests typed from the Hono routes.

- [Read the walkthrough](https://hyperfetch.bettertyped.com/examples/integrations/hono)
- [Open in StackBlitz](https://stackblitz.com/github/BetterTyped/hyper-fetch/tree/main/examples/hono/fullstack)
- [Open in CodeSandbox](https://codesandbox.io/s/github/BetterTyped/hyper-fetch/tree/main/examples/hono/fullstack)

## Run it locally

```bash
npx tiged BetterTyped/hyper-fetch/examples/hono/fullstack hyper-fetch-hono-fullstack
cd hyper-fetch-hono-fullstack
npm install
npm run dev
```
